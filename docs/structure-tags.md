# 結構標籤詞表

> 卡片的 `structure_tags` 只能使用本檔列出的標籤。`npm run validate` 會檢查。
> 本檔同時是程式的資料來源：`scripts/build-index.ts` 解析「## 類別」與「- **標籤**：定義」兩種行。
> 新增標籤時照同樣格式加一行即可。每個標籤下一行縮排寫「白話：…｜例子：…」，學習模式點標籤時會顯示（第 6 期）。

## 地理咽喉

- **海峽封鎖**：控制或切斷一條海峽、海口，使對手的航運或補給中斷。
  白話：卡住別人一定要經過的窄水道。｜例子：就像學校只有一個出口，有人把門堵住，大家都出不去。
- **商路改道**：原本的貿易路線因戰爭、政治或技術而轉移到另一條路線。
  白話：做生意的路線換了一條走。｜例子：捷運站換位置後，原本站前的商店街就冷清了。
- **補給線過長**：軍隊或城市依賴的補給距離過遠，任何一段被切斷就會崩潰。
  白話：前線離後方太遠，東西送不過去。｜例子：外送距離太遠，餐點送到都冷了，還常常被半路攔截。
- **海權對陸權**：一方以艦隊與海上貿易為主力，另一方以陸軍與領土為主力的對抗。
  白話：一邊靠船和海上貿易，一邊靠陸軍和土地。｜例子：一個擅長游泳、一個擅長跑步的人比賽，看比賽場地在哪裡。
- **地形險阻**：山口、森林、沼澤等地形讓兵力或數量優勢無法發揮。
  白話：山、森林、沼澤讓人多也沒用。｜例子：在很窄的樓梯打躲避球，人再多也只能一個一個上。
- **邊疆防線**：以城牆、要塞或河流劃出固定防線來管理邊界與人群移動。
  白話：用城牆、要塞或河流劃出邊界來管人進出。｜例子：社區大門加警衛室，管誰可以進來。
- **單一港口依賴**：大量物資或人口的生計集中依賴少數幾個港口或航線。
  白話：很多東西都靠少數幾個港口或航線進來。｜例子：全班的午餐都靠同一家便當店，店休一天大家就沒得吃。

## 物資與技術

- **關鍵原料壟斷**：一方控制稀缺原料（金屬、糧食等）的產地或供應。
  白話：別人都需要的東西，只有你有或只有你控制。｜例子：全校只有福利社賣立可帶，考試前它說了算。
- **糧食進口依賴**：城市或國家的主食靠遠方進口，外部供應一斷就出現危機。
  白話：主食要靠外地運來，一斷就鬧饑荒。｜例子：家裡冰箱永遠是空的，每餐都靠外送，外送平台一當機就餓肚子。
- **意外財源**：突然出現的大筆收入（新礦脈、戰利品），改變了政策選項。
  白話：突然多了一大筆錢，讓原本不敢做的事變得可以做。｜例子：突然中了發票，就敢買原本買不起的手機。
- **技術代差**：一方掌握對手沒有的關鍵技術或工法，形成能力落差。
  白話：一方有對方沒有的關鍵技術。｜例子：一隊用手機導航、一隊用紙本地圖比定向越野。
- **默會知識外流**：只靠師徒或工匠經驗傳承的技術失傳，或流向其他群體。
  白話：只靠師傅手把手教的技術，人走了技術就跟著走或失傳。｜例子：阿嬤的滷肉沒有食譜，阿嬤不在了，味道就做不出來。
- **技術擴散**：作物、工法或器物隨人員往來傳到新地區並被採用。
  白話：作物、做法或工具跟著人傳到新地方。｜例子：一個班先流行某個遊戲，很快全校都在玩。
- **標準化量產**：用統一規格大量生產器物或建材，降低成本並擴大規模。
  白話：用統一規格大量生產，變便宜又變多。｜例子：手搖飲用量杯和機器封膜，每杯味道一樣、做得很快。
- **基礎建設網絡**：道路、水道、港口等網絡把分散的地區連成一個系統。
  白話：道路、水道、港口把分散的地方連成一個系統。｜例子：捷運路網連起來後，住哪裡都能很快到市中心。
- **資訊傳播革命**：新的書寫、印刷或通訊技術大幅降低複製與傳遞資訊的成本，改變誰能取得知識。
  白話：複製和傳遞資訊變得很便宜，誰能知道什麼就改變了。｜例子：以前要抄筆記，現在拍照傳群組，全班一秒都有。
- **能源轉換**：社會的主要動力來源改變（人力獸力 → 煤與蒸汽 → 電力與石油），帶動生產與運輸方式重組。
  白話：社會主要的動力來源換了。｜例子：從腳踏車換成電動機車，能去的地方和花的錢都不一樣了。

## 聯盟模式

- **聯盟破裂**：原本的同盟因利益或威脅認知改變而瓦解或翻轉。
  白話：原本一起的夥伴翻臉或拆夥。｜例子：分組報告做到一半，組員吵架拆成兩組。
- **霸權挑戰**：崛起中的力量挑戰既有霸主的地位或勢力範圍。
  白話：新崛起的一方去挑戰原本的老大。｜例子：新來的轉學生球技很強，開始挑戰校隊隊長的位置。
- **盟主剝削盟友**：同盟的領導者把盟友的資源轉為自己的財政或權力。
  白話：帶頭的一方把盟友的資源拿去給自己用。｜例子：班費說好給全班用，結果幹部拿去買自己要的東西。
- **代理人戰爭**：大國不直接交戰，而是支持其他勢力代為作戰。
  白話：大國不自己打，而是支持別人去打。｜例子：兩個學長不直接吵架，各自叫學弟去對嗆。
- **附庸反叛**：被統治或依附的群體起兵反抗原本的保護者或統治者。
  白話：被管的一方起來反抗管他的人。｜例子：一直被學長使喚的學弟，有一天一起拒絕。
- **外部勢力介入**：第三方趁兩強相爭時介入，改變勝負或格局。
  白話：兩邊相爭時，第三方跳進來改變結果。｜例子：兩人搶最後一塊蛋糕，第三個人趁亂拿走。
- **雇傭兵與蠻族化軍隊**：國家越來越依賴外部或外族兵力，軍隊忠誠與國家利益脫鉤。
  白話：國家越來越靠外人或花錢請的人打仗，軍隊不一定忠心。｜例子：班際比賽全靠請別班高手代打，贏了也不覺得是自己班的。
- **經濟施壓與制裁**：用關稅、禁運、出口管制或切斷金融管道，代替或配合軍事手段逼對方讓步。
  白話：不打仗，改用不跟你做生意、不賣你東西來逼你讓步。｜例子：隔壁班不守約定，全班決定不跟他們交換社團資源。
- **全面戰爭**：交戰國動員全社會的人力、工業與財政投入戰爭，平民與後方也成為戰爭的一部分。
  白話：全社會的人、工廠和錢都投入戰爭，平民也被捲進去。｜例子：全家都停下工作來搬家，連小孩都要幫忙。

## 金融條件

- **財政枯竭**：長期戰爭或支出耗盡國庫，被迫增稅、借貸或放棄目標。
  白話：國庫的錢花光了，只好加稅、借錢或放棄計畫。｜例子：零用錢月中就花完，只好跟家人借或不出去玩。
- **貨幣貶值**：降低貨幣成色或大量發行，使幣值下降、物價上升。
  白話：錢變得不值錢，東西變貴。｜例子：以前 50 元買得到一個便當，現在要 100 元。
- **債務擴張**：個人或國家的債務快速累積，成為政治衝突的根源。
  白話：欠的錢越來越多，最後變成衝突的原因。｜例子：分期付款越刷越多，每個月光還錢就不夠用。
- **擴大稅基**：透過改變身分、登記或制度，讓更多人或土地納入課稅範圍。
  白話：讓更多人或土地要繳稅。｜例子：原本只有幹部繳班費，改成全班都要繳。
- **公共工程支出**：國家或統治者以大型工程花費來展示權力、創造就業或收買民心。
  白話：政府花錢蓋大工程，展示權力、創造工作或拉攏民心。｜例子：校慶前學校花一大筆錢整修操場。
- **戰爭融資**：用掠奪、賠款、盟友貢金或特別稅支付戰爭成本。
  白話：打仗的錢從哪裡來：搶、賠款、盟友出錢或特別稅。｜例子：辦活動錢不夠，就找贊助、加收費用或跟別班借。
- **金融制度創新**：新的貨幣、銀行、股份或交易所制度，讓分散的資金能集中起來、風險能分攤或轉手。
  白話：新的錢、銀行或股票制度，讓很多小錢可以集中起來，風險可以分攤。｜例子：全班每人出 50 元合買一台投影機，用完還能轉賣。
- **投機泡沫與崩盤**：借貸與投機把資產價格推到遠高於實際收益，最後急跌並波及整體經濟。
  白話：大家借錢搶買，價格遠高於實際價值，最後一起崩。｜例子：限量球鞋被炒到十倍價，熱潮一退沒人要買。
- **惡性通膨**：物價在短時間內暴漲（常見定義是每月上漲超過 50%），貨幣幾乎失去購買力。
  白話：物價漲得非常快，一個月可能翻好幾倍，錢幾乎變廢紙。｜例子：早上 100 元買得到便當，晚上要 200 元。
- **銀行擠兌**：存款人擔心銀行倒閉而同時提款，使原本健全的銀行也可能因現金不足而倒閉。
  白話：大家怕銀行倒，同時去領錢，結果真的把銀行領垮。｜例子：謠傳福利社要收了，大家同時去退儲值卡，福利社真的沒錢退。
- **主權違約**：國家無法或拒絕依約償還債務。
  白話：國家借的錢還不出來，或拒絕照約定還。｜例子：跟同學借錢的人說「我沒錢，不還了」，以後沒人敢借他。
- **貨幣體系轉換**：社會改用新的貨幣、本位或發行制度（例如以銀為本、金本位、新舊幣兌換）。
  白話：一個社會換掉原本用的錢或錢的規則。｜例子：園遊會原本用現金，改成全部用園遊券。
- **金融中心轉移**：資金、商人與金融技術從一座城市移往另一座城市（例如安特衛普→阿姆斯特丹→倫敦→紐約），通常伴隨戰爭、封鎖或霸權更替。
  白話：全世界借錢、換錢、買賣股票最熱鬧的地方，從一個城市搬到另一個城市。｜例子：原本大家都去 A 夜市，A 夜市封街後，攤販和客人全搬到 B 夜市。
- **儲備貨幣地位**：一國貨幣被他國央行、國際貿易與借貸普遍持有和使用，讓發行國借錢較便宜、也能用金融體系施加影響。
  白話：全世界都想存、都拿來做生意的錢，發行它的國家因此占便宜也有影響力。｜例子：全校園遊會都只收某一班發的園遊券，那一班就很好辦事。
- **資本外逃**：資金因恐懼政治或經濟風險而大量移往國外或安全資產。
  白話：有錢人怕出事，把錢大量搬到國外。｜例子：謠傳班費要被沒收，大家趕快把錢拿回家。

## 敘事與制度

- **合法性危機**：統治者或制度失去被統治者普遍接受的正當性。
  白話：大家不再相信統治者有資格管他們。｜例子：班長被發現作弊後，同學不再聽他的。
- **宗教／意識形態動員**：用宗教、神話或意識形態凝聚群體或號召行動。
  白話：用信仰或理念把人團結起來行動。｜例子：用「為班級爭光」號召大家留下來練大隊接力。
- **政治宣傳工程**：用建築、儀式、文字等形式塑造統治者想要的形象與記憶。
  白話：用建築、儀式、文字塑造統治者想要的形象。｜例子：學校在校門口掛滿「升學率第一」的紅布條。
- **法律成文化**：把習慣或少數人掌握的規則寫成公開的成文法。
  白話：把只有少數人知道的規矩寫下來公開。｜例子：把口頭說的班規寫成公告貼在黑板旁。
- **公民身分擴張**：讓更多人取得公民權或政治參與權。
  白話：讓更多人有權參與政治。｜例子：原本只有幹部能投票決定班遊地點，改成全班都能投。
- **精英內鬥**：統治階層內部的派系衝突壓倒對外事務。
  白話：統治階層內部互鬥，顧不了外面的事。｜例子：學生會幹部之間吵架，活動都沒人辦。
- **強人繞過制度**：個人憑軍隊或民意越過既有規則取得權力。
  白話：某個人靠兵力或人氣，跳過規則直接掌權。｜例子：某人人氣很高，沒經過選舉就直接說自己是班長。
- **制度包裝延續**：實質權力已改變，但保留舊制度的名稱與形式。
  白話：實際權力已經換人，但名稱和形式照舊。｜例子：班長還是那個人，但真正做決定的是副班長。
- **重新設計基本單位**：把社會或政治的基本組織單位（部落、戶籍、選區）重新劃分。
  白話：把社會的基本組織重新劃分。｜例子：把原本按座號分組，改成按住的地方分組。
- **思想異見與審判**：社會以法律或公共審判處理挑戰主流價值的人。
  白話：社會用法律或公開審判處理挑戰主流想法的人。｜例子：有同學在週記批評校規，被叫去訓導處。
- **憲政分權**：用成文憲法把權力分給不同機關或中央與地方，彼此制衡，避免任何一方獨大。
  白話：把權力拆開給不同人管，互相盯著，誰都不能一個人說了算。｜例子：班費由總務收、班長簽、導師查帳，三個人缺一不可。
- **革命與政權更替**：以群眾運動或武力推翻既有政權，並改變統治的正當性原則。
  白話：用群眾運動或武力推翻政府，連「誰有資格統治」的道理都改了。｜例子：全班罷免班長，還把選班長的方法整個改掉。

## 節奏

- **慢變結構**：人口、氣候、制度等緩慢累積的變化，數十年到數百年才顯現。
  白話：人口、氣候、制度慢慢累積的變化，幾十到幾百年才看得出來。｜例子：身高每天看不出變化，一年後才發現衣服穿不下。
- **突變事件**：短時間內發生並立即改變局勢的單一事件。
  白話：很短時間內發生、馬上改變局勢的單一事件。｜例子：考試前一天電腦壞掉，報告整個不見。
- **臨界點**：長期累積的壓力在某個時刻跨過門檻，局勢不可逆地轉變。
  白話：壓力累積到某一刻，一下子翻過去回不來。｜例子：杯子裝水一直加，最後一滴就整杯溢出來。
- **長期衰退**：多種因素交織的緩慢衰落，難以指出單一原因或日期。
  白話：很多原因交織、慢慢變差，說不出哪一天開始。｜例子：成績一點一點往下掉，找不到單一原因。
- **快速擴張**：短時間內領土、影響力或網絡急速擴大。
  白話：很短時間內勢力或網絡急速變大。｜例子：新開的手搖店一年展店一百家。
- **疫病衝擊**：大規模傳染病在短期內造成人口銳減，連帶改變勞動、經濟與社會秩序。
  白話：大規模傳染病讓人口大減，連工作和社會秩序都跟著變。｜例子：流感大流行時全班一半請假，連段考都延期。
