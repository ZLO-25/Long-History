# 主題標籤（topics）：把同一件事物串成歷史路徑

2026-11-02 新增。ZL 的需求：點「安特衛普的黃金時代與新交易所」要看到 #交易所，點 #交易所 要看到所有交易所相關的卡，看懂「交易所」的歷史路徑；不限金融，所有層面都要有，而且頁面要清楚、不複雜。

## 和結構標籤的分工

```
結構標籤（藍色，原本就有）   主題標籤（橘色，這次新增）
「發生了什麼樣的模式」       「跟什麼東西有關」
例：債務擴張、臨界點          例：交易所、紙幣、運河、殖民統治
用途：跨時代的結構對照        用途：同一件事物從古到今的路徑
詞表：docs/structure-tags.md  詞表：data/topics.yaml
```

## 規模

6 個層面、61 個主題，182 張卡全部有標（每張 1–8 個，大多 2–4 個），每個主題至少 4 張卡。

|---|---|
| 💰 錢與金融（12） | 鑄幣、紙幣、銀行與借貸、匯票與遠距付款、交易所、股票與公司、國債與公債、泡沫與金融危機、通貨膨脹、中央銀行、國際貨幣、金融中心 |

| ⚔ 戰爭與軍事（7） | 海戰與水戰、游牧民族與邊疆、對外擴張、內戰、火藥與武器、軍事同盟、世界大戰 |

每個主題有三樣東西：`plain`（給國中生的一句白話定義）、`path`（「這條路徑怎麼讀」2–3 句）、`see`（也看看）。

## 怎麼用

```
卡片頁                        主題路徑頁                         地圖／時間軸
┌────────────────────┐ 點  ┌──────────────────────────┐   ┌──────────────────┐
│安特衛普的黃金時代…  │────▶│#交易所                    │   │ 地圖：①②③…編號     │
│主題標籤（點了看路徑）│     │白話定義・8 張卡・1300–1993 │──▶│ 靠太近的合併成     │
│ #交易所 8  #金融中心 │     │這條路徑怎麼讀（2–3 句）    │   │ 「1・2・3・6」     │
└────────────────────┘     │① 1300 布魯日              │   │ 時間軸：只亮這 8 張 │
        ▲                   │② 1501 安特衛普 ←你剛剛看的│   └──────────────────┘
        └──── 點任一張 ─────│③ … ④ 紐約證交所 …         │
                            │也看看：#股票與公司 …       │
                            └──────────────────────────┘
```

- **研究模式**：卡片標頭下方有標籤列；頂列「主題標籤」看全部；手機多一個「主題標籤」分頁，路徑頁有「🗺 在地圖上看」。網址 `?topic=交易所` 直接打開，點開後網址也會跟著變，可以複製分享。
- **學習模式**：學習卡的 💡 下方有標籤列（單元裡的卡也有）；首頁第 2 段「順著一個主題往下走」；頂列 # 按鈕。路徑頁顯示「你讀過 n／m」；還沒做成學習版的卡變灰，點了在新分頁用研究模式打開；學習模式的數字只算學習版的卡。網址 `?mode=learn&topic=交易所`。
- **搜尋**：兩個模式打「交易所」「白銀」等，結果最上面會推薦對應的 #標籤。

## 正確性怎麼確認

1. 每個「卡 → 主題」都用關鍵字比對卡片內文，命中少的逐一人工看上下文，內文沒談到就不標。
2. 每段 `path` 的每個說法都回查該主題的卡片內文（本站規則：只寫卡片查得到的事）。
3. 另請 Fable 5.1 以歷史學者＋UI/UX 角色獨立複查（沒參與寫作），依建議修正：
   - 「起義與民變」改名「民變與抗爭」，二二八寫成「由查緝私菸的衝突擴大為全島抗爭，隨後遭到軍事鎮壓與清鄉」，避免褒貶字眼；安史之亂是節度使叛亂，移出。
   - 移除內文沒依據的 4 個標：黑船來航—火藥與武器、西進擴張—道路與鐵路、二二八—言論與思想管制、兵馬俑—火藥與武器；卡拉卡拉敕令從「民主與參政」移到新主題「公民身分」。
   - 修正 path 裡卡片沒寫的說法（商鞅「准許土地買賣」、羅馬廣場「靠混凝土」等）。
   - 補漏標：茶糖樟腦—原住民族、牡丹社事件—對外擴張、秦漢長城與漢長安城—古代建築、黑死病與鎖國—海上貿易、孔子—科舉與教育。
   - 介面：標籤按鈕加大（手機 32px）、鍵盤焦點外框、「你剛剛看的」改記最後打開的卡、研究模式網址同步、學習模式數字只算學習卡、首頁入口往前移、標籤列加「（點了看歷史路徑）」。

## 維護

- 新卡：frontmatter 在 `structure_tags` 下一行寫 `topics: [...]`；只能用 `data/topics.yaml` 的名稱（`npm run validate` 會擋）。卡片生成工具 `tools/cardgen/gen.ts` 的提示詞已附上詞表。
