# AWMC 古代道路與城牆資料

- 來源：Ancient World Mapping Center（UNC）geodata，<https://github.com/AWMC/geodata>（commit 7ecf8bc，2024-04-22）
- 內容：`roads.geojson`（Cultural-Data/roads）、`walls.geojson`（Cultural-Data/walls）
- 依據：《巴林頓古典世界地圖集》（Barrington Atlas of the Greek and Roman World）數位化
- 授權：ODC Open Database License（ODbL 1.0），見 `LICENSE.txt`；使用時須註明 AWMC
- 欄位（本專案使用）：`Major_or_M`（1＝主要道路）、`Known_or_a`（1＝路線確定，0＝大致路線）、`timeperiod`（A 古風、C 古典、H 希臘化、R 羅馬、L 古代晚期）
  - 欄位意義依名稱與已知道路（如 Via Flaminia 幾乎全為 1）推定，AWMC 文件未逐欄說明。
