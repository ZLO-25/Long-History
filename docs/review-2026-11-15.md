## 〇、我理解的目標

你想知道兩件事：**一個真的來用的人，會覺得這個網站是什麼**；以及**要成為國高中生學歷史的首選、取代課本，還差什麼**。所以這次不是逐項找錯字，而是讓三種專業的人各自「當使用者」走一遍，再從使用方式、學習成果、互動、內容四個方向提出改良。

### 怎麼做的、有什麼限制

```
 │ 24 張卡        │ 斷網、慢網路、列印  │ 量 43 課的字數     │
 │ 程式掃 435 卡  │ 鍵盤、對比、效能    │ 統計 134 題選擇題  │
 └──────────────┴───────────────────┴──────────────────┘
                        ▼
              我彙整、排優先順序、抽查
```

- **限制一**：這個雲端環境連不到 zlo-25.github.io，所以是把 main 最新版在這裡建起來測。內容和功能相同；外部地圖圖磚、Wikimedia 圖片常載不到，所以**卡片圖片這次沒有評**。
- **限制二**：沒有用真的手機、真的螢幕閱讀器，也沒有真的學生。「學生會怎樣」是專業推估，文中有標「估計」。
- **限制三**：很多數字（例如「46／60 題是閱讀測驗」）是評估者用程式或關鍵字規則算的，不是逐題人工判定。我抽查了 4 項（53 張卡沒有學習區塊、比較表文字被切斷、明治維新卡的「302 個藩」、頁首 CSS 撞名），都屬實；其餘沒有逐一複核。

## 一、這個網站是什麼

**一句話：同一批 435 張有出處的歷史卡片，用四種方式帶你讀。**

```
                        435 張卡片（每張有來源、史料、史家怎麼吵、常見誤解、前因後果）
                                          │
      ┌──────────────┬──────────────┼──────────────┬──────────────┐
   學習單元 43 課     故事 26 篇      深入專題 10 個   主題標籤 65 個   研究模式
   一個謎題→12 步     10–25 分鐘      幾課＋勢力圖     同一種事        地圖＋時間軸
   讀卡、決策、        長文＋地圖      ＋人物關係網     跨時代排開      ＋篩選＋曲線
   史料、因果、自評    ＋考考自己                                      ＋今日對照
```

三位評估者各自的說法：

| 誰 | 他眼中的網站 |
|---|---|
| 歷史學者 | 「卡片資料庫＋三種讀法」。從問題出發、把爭議寫出來，這兩點比課本好。史觀偏政治經濟與制度，選材偏錢、戰爭、帝國興亡、希臘羅馬、日本戰國。 |
| UI/UX | 「同一批卡片的兩個外殼」：學習模式給學生、研究模式給老師。功能很多，但入口太多、名字不統一。 |
| 教育心理學者 | 「謎題開場、卡片當教材、少量題目收尾」的引導式探究教材。實測單元畫面 85% 的文字在讀卡片，每課會對答案的題目平均只有 4 題，所以**目前更像一本寫得很好、附少量習題的互動讀本，還不是以練習為主的學習系統**。 |

**跟課本最大的不同**

```
   課本                                歷史長河
   ─────────────────────             ─────────────────────────────
   從朝代、名詞開始             →      從一個謎題開始
   只給一個說法                 →      「史家怎麼吵」、死亡人數並列多種估計
   因果是一句話                 →      因果是可點的連線，分 直接引發／促成／背景
   今昔對照點到為止             →      每課都問「這個類比哪裡不成立」
   你是讀者                     →      你先當決策者（掩卷自思），再看歷史怎麼走
```

**三位一致的結論：現在是很好的補充與探究教材，還不能取代課本。** 原因有三個，後面分別展開：

1. 課綱核心內容有缺口，而且有 53 張核心卡在學習模式根本打不開。
2. 讀得多、練得少，沒有隔天再練的機制，學生讀完容易「以為懂了」。
3. 老師看不到學生有沒有認真做，也找不到「這一課對應課本哪裡」。

## 二、做得好的（請保留，不要在改良時弄丟）

1. **爭議與不確定寫得誠實**。二二八並列 7 種死亡估計並說明算法；戒嚴卡寫「哪個數字對，取決於怎麼定義受害」；圖說註明後世畫作不是當時紀錄。
2. **「掩卷自思 → 選 → 看實際 → 回到自己」的決策流程**。先預測再看結果是有研究支持的做法；沒發生的路標明是「推測」。
3. **43 課的今日對照都先問「哪裡不成立」**，很少教材做得到。
4. **故事閱讀頁是全站最好的畫面**。手機版面乾淨、名詞就地解釋、每節一句重點、地圖會跟著段落亮；三位都點名。
5. **效能與容錯**。處理器放慢 4 倍仍不掉幀、版面位移 0；研究模式搜尋對錯字、簡體、拼錯的英文都耐打；底圖載不到時地圖仍可用。
6. **新一批單元的題目可以當全站範本**：`unit-rome-2`、`unit-sapiens-science`、`unit-where-from`、`unit-america-rise` 已經在問「哪個說法最穩妥」「讀這句話最需要注意什麼」。

## 三、可能的學習成果

```
  學生認真做完幾課之後
  ┌─────────────────────────────┬─────────────────────────────────┐
  │ 大概會得到                    │ 不太會得到                        │
  ├─────────────────────────────┼─────────────────────────────────┤
  │ ✔ 因果理解（為什麼，不是哪年） │ ✘ 記得住（沒有隔幾天再考一次）     │
  │ ✔ 知道歷史有不同說法          │ ✘ 自己判斷史料可不可信             │
  │ ✔ 對「歷史會重演」保持戒心     │ ✘ 完整的年代骨架                  │
  │ ✔ 把歷史連到自己              │ ✘ 寫出有論證的答案                 │
  │ ✔ 知道事情發生在哪裡          │ ✘ 把學到的道理用到新案例           │
  │ ✔ 對原本沒興趣的題目好奇       │ ✘ 知道自己會了什麼、考試會考哪裡   │
  └─────────────────────────────┴─────────────────────────────────┘
```

用課綱的話說：**「歷史解釋、多元觀點」強；「因果」中等；「史料證據」中偏弱；「時序」弱。**

為什麼右邊那一欄得不到，原因很具體：

| 得不到的 | 實際看到的原因 |
|---|---|
| 記得住 | 33／43 課有連續 3 步以上只讀不答；題目集中在最後；全站沒有間隔複習；「複習」只是回到最後一步 |
| 判斷史料 | 史料題約 46／60 題只要把文言對到白話翻譯就能答；「誰寫的、為什麼這樣寫」是寫在解析裡給學生看的 |
| 年代骨架 | 內容不按年代；前 500–西元 500 年有 125 張卡，500–1000 年只有 17 張 |
| 有論證的答案 | 開放題空白也能看參考說法；全填「asdf」照樣拿獎章 |
| 用到新案例 | 單元結尾只有連結，沒有「拿這一課的想法解另一個案例」的題目 |
| 知道自己會了什麼 | 不作答連按下一步，約 15 秒就「完成」；封面的「學完你會」到結尾沒有再出現 |

## 四、建議的優先順序

排序原則：**先修「現在就壞掉」的，再修「做不完一課」的，再做「讓老師敢派作業」的，最後才是擴充內容。** 影響＝對學生學習或能不能用的影響；工夫＝實作量。全部都在「靜態網站、無後端、不串 AI」的限制內。

```
  第 1 級            第 2 級              第 3 級             第 4 級            第 5 級
  現在就壞掉   →    一課做得完、        老師敢派作業   →    內容補洞     →    收尾
  （1–2 天）        學得進去            （有憑有據）        （長期）
                    （最值得投資）
```
