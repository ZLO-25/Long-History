# 用語表（給寫畫面文字、題目、說明的人）

2026-11 統一（review #18）。**畫面上對學生說的話一律照這張表**。資料 id、網址參數、程式裡的變數名稱不改（例如 `unit-xxx`、`?unit=`、`view=dives`），只改學生看得到的字。

## 對學生的名稱

| 學生看到的字 | 指什麼 | 不要這樣叫 |
|---|---|---|
| **課**（一課、這一課、挑一課、43 課、第 3／3 課） | 一個學習單元：從一個問題開始、約 5–25 分鐘做完的一段導讀 | 單元、學習單元、謎題（指整課時） |
| **謎題** | 只指「這一課開頭的那個問題」（封面上 ❓ 後面那一句） | 不要拿來稱呼整課 |
| **深入專題** | 花幾課把一段歷史看透：一個大問題＋照順序的幾課＋隨年份變化的地圖＋相關卡片 | 專題、大專題 |
| **跨地區主題** | 首頁「依地區與主題」裡，不屬於某個地區的 XX史（錢的歷史、科技史…）。資料的 `track: 專題` 不改 | 專題（跨地區） |
| **#標籤** | 卡片上的主題標籤，點了看同一件事物從古到今的路徑 | 主題標籤、標籤頁 |
| **故事線** | 一串站：一件事怎麼引出下一件事，每兩站之間有一條因果 | 路線（路線指地圖上的路） |
| **故事** | 故事線的那篇 10–25 分鐘長文。首頁入口叫「📖 讀故事」 | 故事線（指長文時） |
| **📖 故事** | 學習卡裡的那一節（`learn.story`）。維持這個名字 | |
| **卡片** | 一張卡（事件、人物、地點…） | |
| **XX史**（臺灣史、錢的歷史…） | 看歷史的一個角度。首頁入口叫「依地區與主題」 | |
| **課綱對照** | 課綱條目 ↔ 這個網站的課與故事（`?mode=learn&view=curriculum`） | |
| **年級**（國中／高中／國高中皆可） | 資料欄位 `level`：國中／高中／皆可 | |

## 畫面位置

- 手機底部分頁：**首頁｜卡片｜地圖｜時間軸**。第一個分頁裡裝的是首頁、XX史、深入專題、#標籤、紀錄等所有清單與課，所以叫「首頁」。
- 「卡片」分頁沒開卡時：寫「還沒打開任何卡片」＋一顆「去挑一課」。從標籤頁、清單點卡片跳到「卡片」分頁時，上方有「← 返回」。
- 頁首（學習模式）：故事線｜深入專題｜#標籤｜我的地圖｜紀錄。手機版與桌機版同名，不縮寫成「專題」「#」。
- 首頁四個入口：依地區與主題（XX史）／讀故事／深入專題／#標籤。

## 研究模式（共用元件）

- 頁首按鈕：深入專題、#標籤（原本是「專題」「主題標籤」）。
- 手機版卡片小節標題不顯示 `C1` 這種內部編號，也不顯示「核心／深入／選填」（桌機照舊，那是給寫卡片的人看的）。

## 寫文案的小規則

1. 第一次出現「課」的地方，可以補一句「每一課從一個問題開始」。
2. 計數用「N 課」「N 張卡」「N 條故事線」「N 個深入專題」「N 個標籤」。
3. 「步」是一課裡的步驟（第 3／12 步）；「課」是整個單元。兩個不要混用。
4. 對老師的頁面（學習單、老師檢視）也用同一組字。
