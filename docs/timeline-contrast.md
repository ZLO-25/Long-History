# 時間軸文字加深（2026-11-03）

ZL 回饋：時間軸字太淺，操作時看不清楚。要求：字放大 12px → 13px，年代數字、事件名稱、時代標籤全部加深。

## 改了什麼

| 文字 | 原本 | 現在 | 對比度（在刻度列底色 #f1ede4） |
|---|---|---|---|
| 年代刻度數字 | 11px、#6f6a62 | 12px、#3f3b35、字重 500 | 4.6 → 9.5 |
| 事件名稱（研究） | 12px | 13px、字重 500 | 近黑，>12 |
| 事件名稱（學習） | 12.5px | 13.5px、字重 500（色塊內白字 12.5px） | 近黑 |
| 軌道名稱（中國與東亞、西方…） | 11px、#8a8378 | 12px、#3f3b35 | 3.2 → 9.5 |
| 背景軌大事（學習） | 11px、#8a8378 | 12px、#3f3b35 | 3.6 → 10.7 |
| 時代色塊字（學習總覽） | 13px、#4a5568 | 14px、#2d3748 | 6.1 → 9.7 |
| 「還沒有卡片」說明 | #8a8378 | #57524a | 3.0 → 6.2 |
| 時代切換列、正在看、說明列 | 12–12.5px | 13px、#3a362f／#4a4741 | ≥7.4 |
| 研究模式點了卡後，其他卡 | 整個透明度 0.35 | 色條 0.4、名稱深灰 #3a362f 不透明（ZL 追加要求） | 被點的卡仍是粗體近黑 |

所有文字都達 WCAG AA（一般文字 4.5:1）。全域 `--muted` 沒動，只在時間軸範圍內覆寫。

## 版面配合
- 字寬估算：研究 `LABEL_PX` 12.5→13.5、學習 `CH_W` 13→14，標籤放不下時照舊自動截短或併入「+N」。
- 刻度數字最小間距 46→50（研究）、44→48（學習）；紅線年份膠囊加寬。
