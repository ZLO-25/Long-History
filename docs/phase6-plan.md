## 0. 我理解的目標

**目標**：讓國高中生不靠老師、不照課本順序，自己挑想學的「XX史」，從一個好奇的謎題開始，讀故事、看證據、自己判斷，答完再被帶到下一個謎題。

**要解決的問題**：現在的歷史長河是「研究用的查資料工具」——打開是一堆點和橫條、一張卡 10 多段、引用代號密集、來源多是英文維基、臺灣與東亞幾乎是空的。學生不知道從哪開始、卡住也沒人幫。

```
同一批卡片資料
      │
      ├──► 研究模式（給 ZL）：完全不動
      │
      └──► 學習模式（給學生）：
             選「XX史」→ 謎題 → 故事 → 證據 → 自己判斷 → 下一個謎題
```

## 7. 我會自己決定的事（不用你回）

- 文明名稱改中性寫法只在學習模式顯示（例「中國（秦）」→「秦朝（今中國）」），研究模式不改，避免舊網址失效。
