# 第二次教學檢視＋呂世浩讀史方法改良（2026-11-01）

> 上一次檢視（`docs/pedagogy-review.md`，2026-10-26）之後，站上多了第 7、8 期（美國史、金融中心、古代的錢：46 卡、6 個單元）。本檔重新審視整體，並依呂世浩老師公開談過的讀史方法小幅改良。方法與引用邊界見 `docs/lu-method.md`。

                                           └─ 沒被任何單元用到 33 張

**1. 二十世紀的世界史有卡、沒有單元。** 冷戰（圍堵與北約、韓戰、越戰、尼克森訪中）、大蕭條、布列敦森林、金本位、廣場協議與日本泡沫、亞洲金融風暴、2008 金融危機都已是學習卡，但學生只能零散讀，沒有一條「謎題 → 因果 → 決策」的路帶他們走。這是下一輪最值得做的單元。

**2. 鴉片戰爭沒被任何單元用到。** 它是國中東亞史近代的起點；「黑船來了」單元講日本，沒有把清朝這一邊用起來。

**3. 長單元。** 錢的起源 50 分鐘、20 步，是全站最長；金融中心、美國崛起已拆成上下兩半，錢的起源也值得拆。

**4. 決策步驟是全站最能「把自己放進去」的地方，但原本是直接選選項。** 學生容易憑直覺點一個，看完結果就走，沒有先停下來想。

**5. 回顧只回答謎題，沒有回到學生自己。** 單元教了「發生什麼、為什麼」，但沒有問「這對我有什麼用」。

## 二、依呂世浩讀史方法做的改良

呂老師在〈《史記》中的智慧〉一文中說「不是歷史變得無用，是我們學歷史的方法有問題」，並轉引宋代呂祖謙：讀史要「如身在其中」，讀到關鍵處「掩卷自思，使我遇此等事，當作何處之」（來源與邊界見 `docs/lu-method.md`）。本站把它做成三個小改動：

```
 決策步驟                                   回顧步驟
 ┌──────────────────────────┐              ┌──────────────────────────┐
 │① 先別看選項：寫下你會怎麼做│              │④ 用自己的話回答謎題       │
 │   （可以跳過）            │              │   參考說法「不是標準答案」 │
 ├──────────────────────────┤              ├──────────────────────────┤
 │② 選一個 → 結果 → 實際發生 │              │⑤ 🪞 回到自己              │
 ├──────────────────────────┤              │   每個單元一題反思         │
 │③ 對照一下（三問）         │              │   （17 題，各自從單元裡的 │
 │  ・當時的資訊與壓力？     │              │    一個真實選擇出發）      │
 │  ・你的直覺和他差在哪？   │              └──────────────────────────┘
 │  ・代價最後誰付？         │
 └──────────────────────────┘
```

另外：

- 學習首頁加「📜 為什麼要學歷史？」說明框：先有問題、把自己放進去、看成敗也看代價、回到自己。明寫哪些是呂老師的原話、哪些是本站整理。
- 單元新欄位 `reflect`；`npm run validate` 會提醒沒寫 reflect 的單元，也會擋 reflect 裡出現來源代號（反思題不放新史實）。
- 學生寫的想法只存在自己的瀏覽器，不評分。

## 三、秦的興亡示範單元（ZL 選擇加做）

秦漢是國中中國史重點，也是呂世浩 Coursera 課程〈秦始皇〉的主題，但全站原本沒有秦漢單元。本輪：

- 5 張已查證的秦漢卡（商鞅變法、秦統一、焚書坑儒、陳勝吳廣、漢承秦制）補上學習區塊，經獨立查核通過。查核者修正：客舍拒宿出處補〈商君列傳〉、嬴政即位年前 247／前 246 並列、China 詞源並列多說、陳勝卡把新世界百科的評語誤當司馬光的話已改正、刪掉無來源的「奠定兩千年制度」。
- 新單元 `unit-qin-rise-fall`「秦的興亡：十年統一天下，為什麼十五年就亡了？」用「看成敗也看代價、盛的時候找衰的種子」來讀：決策步驟讓學生當前 209 年大澤鄉遇雨誤期的屯長；比較步驟問「同一套制度，為什麼秦短漢長」，並列多位學者看法；回顧提醒「坑儒」「暴秦」形象的史料爭議。
- 單元內文不寫「呂世浩認為」，只借用讀史方法；商鞅卡只寫「呂世浩把商鞅列為 Coursera 課程某單元的主題」，並註明那是課程介紹文字。

```
商鞅變法 ─► 滅六國 ─► 統一制度 ─► 焚書 ─► 大澤鄉誤期 ─► 陳勝起事 ─► 秦亡、漢承秦制
(前 356)   (前 230–221)            (前 213)  (前 209)                    (前 202)
   └──── 讓秦變強的東西 ─────────────────────► 也是讓它很快崩潰的東西？（本單元的謎題）
```
