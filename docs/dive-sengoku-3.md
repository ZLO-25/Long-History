## 二、修了什麼

**內容**（約 23 張卡、5 個單元、故事線）
- 新卡「薩摩入侵琉球（1609）」，補上戰國專題原本缺的南方一角。
- 秀吉與將軍、高砂國與西班牙、1634 年禁赴臺／1635 年全面禁出國、鄭芝龍與李旦、壬辰後 1605 講和／1607 復交等處改寫。
- 常見誤解搬到「戲劇 vs 史實」，12 張卡補齊。
- 單元：決策題一律移到「還沒看到答案」的位置；單元順序 1 → 2 → 3 → 壬辰 → 4。

**介面**
- 時間軸軌道改淡色交替；關係網修正自連線、顏色統一、色盲友善線型、鍵盤與觸控操作。
- 決策題選項依單元與步驟做固定洗牌（YAML 不動）。
- 學習首頁、日本史頁有專題入口；單元頁顯示「第 N／M 課」與「專題下一課」；卡片顯示所屬專題。
- 勢力圖預設打開專題起點之後的第一張；圖例最多 8 列；地圖標籤避免重疊；人生軌跡年份太近時合併。

**獨立查核**：兩位查核者（未參與寫作）查 24 張卡、5 個單元與專題設定，全部通過，其中 17 處改過才通過。例：本能寺卡武田滅亡改西曆 4 月；種子島傳入明朝改「確切年份不明、最晚 1548」；二十六聖人改回來源原文「第一次」；琉球卡 1879 改「廢琉球藩、設沖繩縣」。

## 三、模板去戰國化

設計稿列出 24 處寫死，21 處必改，全部完成；另外掃到介面修正新增的 4 處也改了。

```
 data/dives/<id>.yaml
   visual: power | curve | none     ← 主視覺可選（目前 power 有畫面）
   power_ui: { title, blurb, ... }  ← 「勢力圖／領土擴張圖」的名稱與說明
   view: 地圖範圍
 data/dives/<id>/power-<年>.yaml    ← 每個區塊可設 minor（小勢力收進「其餘 N 個」）
 data/ne/<底圖>.geojson             ← npm run basemap -- US 下載 Natural Earth 州界
```

- 沒有人物卡的專題自動隱藏人物區與關係網。
- `scripts/qa/dive.cjs` 對每個專題都跑一輪通用檢查，戰國另有加碼檢查。

## 四、美國崛起（試套）

- 1763–1991，37 張既有卡、2 條故事線、3 個單元；沒有寫新卡。
- 領土擴張圖 1783／1803／1821／1848／1898，底圖為 Natural Earth 50m 州界。說明見 `docs/dive-usa.md`。
- 已知限制：1898 年夏威夷縮小時太小、阿拉斯加在預設視野外；沒有美國人物卡，所以沒有關係網。

## 五、戰國勢力圖文字修正

- 1560、1600 標題改西曆月份，舊曆放括號。
- 1590 伊達：山形南部（置賜）＋福島東部（伊達・信夫）＋宮城南部；宮城北部為葛西・大崎舊領（木村吉清）。
- 1615 長崎：註明 1641 年荷蘭人遷出島後才是唯一對歐窗口。
- 地圖圖例「疆域示意」跟著選的年份走。
