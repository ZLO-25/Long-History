## 3. 每個指標有幾個點、哪些年代沒有資料

```
年代     前800   前500   前200    1     200    500
人口                       ○    ●○○  ○  ●     （漢、羅馬、Maddison）
人均GDP                          ●            （只有西元 1 年）
銀幣含銀率                ━━━━━━━━━━━━━━━●●   （前 211 到 274 年）
```

- **人口**：17 個點，集中在前 70 年到西元 164 年。前 800 到前 100 年、以及 200 到 500 年都沒有可靠的總人口數字，因此留白。
- **人均 GDP**：Maddison 2020 在本時間軸範圍內只有西元 1 年；下一個點是 730 年或 1000 年，超出範圍，只寫在點的說明裡。計畫原本寫「1 年與 1000 年」，因為 1000 年不在時間軸上，所以改成只畫 1 年。**中國沒有點**：Maddison 2020 沒有中國西元 1 年的人均 GDP，最早是 1000 年的 1,225。
- **銀幣含銀率**：19 個點，涵蓋前 211 年到 274 年，只有羅馬。**中國沒有對應曲線**：查不到漢代五銖錢逐期的重量或含銅量實測序列。這是「無適當對照」，不是漏做。

## 5. 已知問題與限制

1. **大部分物資鏈是點線**。只有埃及穀物和貝提卡橄欖油兩條鏈，有一段沿著真正算過的航線；其他都是「路線示意」，因為史料沒有留下實際走法，或本庫還沒有那段路線（例如普泰奧利到奧斯提亞的海路、台伯河、瓜達幾維河河運）。
2. **漢代鐵官鏈只有兩個節點**。冶鐵遺址的座標用今鄭州市示意；鐵器怎麼運到各郡、賣給農民，來源不足，所以沒畫。
3. **絲綢鏈用泰西封代表安息**。這是本卡的代表點，不是說絲綢一定經過泰西封。
4. **手機版沒有經濟帶**。手機版沒有時間軸，只用年代滑桿，所以經濟曲線只在電腦版提供；物資鏈在手機版可以播放，地圖下方會顯示節點清單。
5. **Seshat 資料庫與 Maddison 官網在這個環境連不上**。Maddison 改從 OWID 在 GitHub 公開的 MPD 2020 CSV 取得；Seshat 的政權人口資料沒有用上。
6. **「官方登記」不等於實際人口**。嚴耕望的研究指出，中央收到的戶口數常常低估實際人數。教人時請把這點和數字一起講。
