## 我理解的目標

讓一個第一次點進網址的國高中生，不用人教，就能自己找到題目、讀完一課、知道自己學到什麼。

## 我怎麼看的

用桌機（1366×768）與手機（390×844）實際打開首頁、學習模式首頁、「臺灣史」頁、卡片頁，
並從頭到尾走完「西羅馬為什麼會亡」13 步。

```

 ──────────────                 ────────                    ────────

                            一堆篩選鈕）要自己找「學習模式」      記住上次用的模式；舊連結照舊進研究模式
```
