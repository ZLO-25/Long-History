# 結構標籤詞表

> 卡片的 `structure_tags` 只能使用本檔列出的標籤。`npm run validate` 會檢查。
> 本檔同時是程式的資料來源：`scripts/build-index.ts` 解析「## 類別」與「- **標籤**：定義」兩種行。
> 新增標籤時照同樣格式加一行即可。

## 地理咽喉

- **海峽封鎖**：控制或切斷一條海峽、海口，使對手的航運或補給中斷。
- **商路改道**：原本的貿易路線因戰爭、政治或技術而轉移到另一條路線。
- **補給線過長**：軍隊或城市依賴的補給距離過遠，任何一段被切斷就會崩潰。
- **海權對陸權**：一方以艦隊與海上貿易為主力，另一方以陸軍與領土為主力的對抗。
- **地形險阻**：山口、森林、沼澤等地形讓兵力或數量優勢無法發揮。
- **邊疆防線**：以城牆、要塞或河流劃出固定防線來管理邊界與人群移動。
- **單一港口依賴**：大量物資或人口的生計集中依賴少數幾個港口或航線。

## 物資與技術

- **關鍵原料壟斷**：一方控制稀缺原料（金屬、糧食等）的產地或供應。
- **糧食進口依賴**：城市或國家的主食靠遠方進口，外部供應一斷就出現危機。
- **意外財源**：突然出現的大筆收入（新礦脈、戰利品），改變了政策選項。
- **技術代差**：一方掌握對手沒有的關鍵技術或工法，形成能力落差。
- **默會知識外流**：只靠師徒或工匠經驗傳承的技術失傳，或流向其他群體。
- **標準化量產**：用統一規格大量生產器物或建材，降低成本並擴大規模。
- **基礎建設網絡**：道路、水道、港口等網絡把分散的地區連成一個系統。

## 聯盟模式

- **聯盟破裂**：原本的同盟因利益或威脅認知改變而瓦解或翻轉。
- **霸權挑戰**：崛起中的力量挑戰既有霸主的地位或勢力範圍。
- **盟主剝削盟友**：同盟的領導者把盟友的資源轉為自己的財政或權力。
- **代理人戰爭**：大國不直接交戰，而是支持其他勢力代為作戰。
- **附庸反叛**：被統治或依附的群體起兵反抗原本的保護者或統治者。
- **外部勢力介入**：第三方趁兩強相爭時介入，改變勝負或格局。
- **雇傭兵與蠻族化軍隊**：國家越來越依賴外部或外族兵力，軍隊忠誠與國家利益脫鉤。

## 金融條件

- **財政枯竭**：長期戰爭或支出耗盡國庫，被迫增稅、借貸或放棄目標。
- **貨幣貶值**：降低貨幣成色或大量發行，使幣值下降、物價上升。
- **債務擴張**：個人或國家的債務快速累積，成為政治衝突的根源。
- **擴大稅基**：透過改變身分、登記或制度，讓更多人或土地納入課稅範圍。
- **公共工程支出**：國家或統治者以大型工程花費來展示權力、創造就業或收買民心。
- **戰爭融資**：用掠奪、賠款、盟友貢金或特別稅支付戰爭成本。

## 敘事與制度

- **合法性危機**：統治者或制度失去被統治者普遍接受的正當性。
- **宗教／意識形態動員**：用宗教、神話或意識形態凝聚群體或號召行動。
- **政治宣傳工程**：用建築、儀式、文字等形式塑造統治者想要的形象與記憶。
- **法律成文化**：把習慣或少數人掌握的規則寫成公開的成文法。
- **公民身分擴張**：讓更多人取得公民權或政治參與權。
- **精英內鬥**：統治階層內部的派系衝突壓倒對外事務。
- **強人繞過制度**：個人憑軍隊或民意越過既有規則取得權力。
- **制度包裝延續**：實質權力已改變，但保留舊制度的名稱與形式。
- **重新設計基本單位**：把社會或政治的基本組織單位（部落、戶籍、選區）重新劃分。
- **思想異見與審判**：社會以法律或公共審判處理挑戰主流價值的人。

## 節奏

- **慢變結構**：人口、氣候、制度等緩慢累積的變化，數十年到數百年才顯現。
- **突變事件**：短時間內發生並立即改變局勢的單一事件。
- **臨界點**：長期累積的壓力在某個時刻跨過門檻，局勢不可逆地轉變。
- **長期衰退**：多種因素交織的緩慢衰落，難以指出單一原因或日期。
- **快速擴張**：短時間內領土、影響力或網絡急速擴大。
