# 人群圖層：第 1、2 期報告與更新方式（2026-11-08）

網址：`?mode=research&peoples=intro`（說明＋圖例）、`?peoples=Taiwan`（臺灣放大鏡）、`?peoples=about`（為什麼不畫人種）、`?peoples=<Natural Earth 國名>`（例如 `India`）、`?peoples=migrations`（八條大遷徙）、`?peoples=mig-<id>`（例如 `mig-austronesian`）。學習模式加 `mode=learn` 一樣能用。

## 目標

讓學生在地圖上點一個地方，就看得出「這裡主要住的是哪些人」（第 1 期），再看「他們是怎麼一路移動到這裡的」（第 2 期）。

```
 ◎ 人群（地圖右上角）
   │
   ├─ 國家顏色 ＝ 多數人母語所屬的語系（主要，不是全部）
   ├─ 小圓點   ＝ 一種語言的代表位置（Glottolog），不是人數
   ├─ 點國家   ─▶ 右欄：族群比例、語言比例、怎麼算的、資料年份、原文連結
   ├─ 臺灣     ─▶ 放大鏡：族群組成、認同≠語言、17 個原住民族、平埔族群
   ├─ 說明頁   ─▶ 為什麼不畫「人種」：三個理由＋三種問法
   └─ 遷徙     ─▶ 八條大遷徙清單（時間尺）
                    └─ 單條：沿途各站＋四種證據＋學界還在爭的事＋今天＋相關國家／卡片
                       地圖右下角時間播放（手機在上方），站點依年代長出來
```

### 查核時發現、已處理的事（第 2 期）

- 來源主要是英文維基百科，加上 SlaveVoyages、PBS（沿用大西洋奴隸貿易卡已查核的數字）與 3 篇論文的 DOI。容器連不到維基百科，用網頁讀取代理逐頁讀；被截斷、只剩模型摘要的句子一律不用。
- 維基百科各頁之間有矛盾的，直接寫出來：南島出發年代（前 3000–1500 年 vs 5,000–6,000 年前）、班圖年代、安德羅諾沃與吠陀的年代、突厥遷徙範圍（6–11 vs 5–16 世紀）、歐洲移民總數（6,000 萬 vs 6,500 萬）、奴隸貿易人數（1,252 萬 vs 1,275 萬 vs 940–1,260 萬）。
- Heggarty 等 2023（印歐「混合說」）不在讀到的頁面上，所以沒有寫；改寫 2024–2025 年研究把源頭往高加索－下伏爾加推（顏那亞頁）。
- 西臺人：西臺頁寫祖先可能前 4400–4100 年就到安納托利亞，和草原說時間不合，列在爭議。
- 艾利斯島、鄂圖曼、塞爾柱、凱魯萬、伊比利、卡迪西亞、雅庫特、夏威夷、馬達加斯加的年份，另外逐頁確認原文。
- 新加坡不在 Natural Earth 國家清單裡，漢人南移的相關國家沒有列新加坡（站點仍有）。
- 獨立查核（另一次呼叫、未參與寫作，逐頁讀來源）：結論「通過，需修正」；已修 20 多處，包括塞爾柱、雅庫特的路線接錯、大馬士革與統一半島的年份、客家南遷的事件沒有來源、番禺年代、「血統」改「祖先」、種族那句移到爭議並寫明是社會分類。無法驗證的：Micheletti 2020 摘要、Fortes-Lima 論文的「約 4,000 年前」（只有維基寫）。


## 為什麼不畫「人種」

1. 人的外表是漸變的，遺傳差異大多在同一群人內部、而且連續（Wikipedia: Race (human categorization)）。
2. 種族是社會訂的分類，證據就在各國資料：美國用普查的「種族」類別、巴西最大群是「混血」、南非有「有色人」、多明尼加的「印第歐」不一定有原住民祖先、日本與德國只統計國籍。
3. 所以圖上看三件事：說什麼話（語系，地圖顏色）、認為自己是誰（各國族群統計）、祖先從哪裡來（古 DNA，第 2 期）。

### 查核時發現、已處理的事

- **西拉雅族 2026-07-30 獲行政院認定為第 17 個原住民族**（第一個依《平埔原住民族群身分法》認定的平埔族群）。Factbook 還寫 16 族，本站改成 17 族，並在臺灣頁說明。
- 內政部 2025 年底統計只公布前三大族人數（阿美 23.5 萬、排灣 11.4 萬、泰雅 10.3 萬，合占 72%）。其他各族沒有找到可開啟的最新數字，所以不寫人數，連到原民會。
- 客家人口 466.9 萬（19.8%）在一篇報導寫 110 年資料、另一篇寫 2023 年調查；本站採客委會自己發布的「110 年」。
- 2016 年的各族人數表（Wikipedia）太舊，不採用。
- Glottolog 的國家欄位把臺灣的語言標成 CN，本站不使用這個欄位。
- Glottolog 把太魯閣語併在賽德克語裡，太魯閣族用花蓮秀林一帶的示意點，並標「示意」。
- 族群統計方式各國不同（民族、國籍、祖源、種族、出生地），每張國家卡都寫「怎麼算的」，提醒不能直接跨國比較。
- 補充說明裡沒有來源的年代與推論都刪掉了（例如毛利人抵達年代、匈牙利人遷入年代、盧安達普查政策）。

### 上色規則

- 「語系」＝多數人的母語所屬語系，依 Factbook 的族群與語言比例判斷。
- 好幾個語系人數相近（例如奈及利亞、查德、蘇利南）畫成灰色虛線框（mix），國家卡寫明是哪幾個語系。
- 外來移工占多數的國家（阿聯、卡達）也算 mix。
- 克里奧爾語為主的國家（海地、牙買加）單獨一色；Glottolog 本身把克里奧爾語歸到詞彙來源的語系。
- 美洲、新幾內亞、澳洲的原住民語言分屬幾十個語系，語言點合成三個「諸語系」顏色，圖例寫明「這是地理群組，不是一個語系」。

## 畫面

- 地圖右上角「◎ 人群」：打開時隱藏古代疆域、案例地點、路線與古道（圓點太像語言點，容易看混）；關掉後恢復。
- 圖例：前 13 個語系色票＋「語言點」開關；完整圖例在說明頁。
- 臺灣：放大到 6 級以上顯示族名，重疊的先藏起來（官方承認的優先）；8 級以上顯示英文名。
- 國家卡：語系徽章、補充說明、「怎麼算的」、族群與語言比例長條、資料年份、Factbook 原文連結（固定版本）。

## 更新方式

```
npm run peoples          # 重新下載 Glottolog（固定 v5.2.1）與 Natural Earth 50m，產生 languages.json、countries-50m.geojson
npm run build:index      # 編譯 public/data/peoples*.json（npm run dev／build 會自動做）
npm run validate         # 檢查每個國家都有資料、語系代碼正確、臺灣頁來源都存在；遷徙每站每句都有來源、from 指得到、卡片與國名存在
node scripts/qa/peoples.cjs http://localhost:5173/   # 46 項畫面測試
```

改某國資料：編 `data/peoples/countries.yaml` 那一行。格式見檔頭註解；族群、語言用全形分號「；」分開，每項最後的數字是百分比。

改遷徙：編 `data/peoples/migrations.yaml`（規則見檔頭）。文字一律用單引號包起來，因為內容常有逗號（例如「1,257」），沒包會被 YAML 拆壞。

## 第 3 期：學習單元「你家從哪裡來？」（2026-11-09）

單元 `data/units/unit-where-from.yaml`，約 45 分鐘、14 步。網址 `?mode=learn&unit=unit-where-from`。

```
上半（約 20 分）                               下半（約 25 分）
引子 ─► 為什麼不畫人種 ─► 臺灣放大鏡 ─► 南島語族   ─► 清代渡臺卡 ─► 你是決策者 ─► 比較（渡臺 vs 奴隸貿易）
     ─► 西拉雅卡 ─► 史料（麻豆和約）─► 漢人南移  ─► 因果鏈 ─► 今日對照 ─► 自我檢查 ─► 回顧＋反思
```

主軸：「說什麼話、認為自己是誰、祖先從哪裡來」三件事常常不一樣，再加第四問「自己選的，還是被迫的」。

**新的步驟類型 `peoples`**（第一次用在這個單元）：在單元裡顯示人群圖層的一頁，右邊（手機是「地圖」分頁）的地圖同步打開「◎ 人群」並跳到那一頁。

- 在這一步裡點別的國家或遷徙：在單元裡換頁、地圖跟著跳，有「← 回到這一步」，不會離開單元。
- 步驟名稱寫出頁名（例如「看人群地圖・臺灣放大鏡」）。
- 手機有「點這裡到地圖看 ▶」直接切到地圖分頁；比較表在手機改成直排小卡。
- 學習模式點到人群頁時，地圖圖例先收起，免得蓋住臺灣。
- `ref` 也可以寫 `peoples:Taiwan` 這種，答錯時按鈕會回到那一頁。寫法見 `docs/learn-units.md`。
