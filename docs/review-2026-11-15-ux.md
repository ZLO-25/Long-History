## 一、最重要的三件事

1. **最新一版（故事地圖）把學習模式的頁首弄壞了**。手機和平板只要點過任何一個「XX史」、單元、卡片或故事線，頁首就有 6 顆按鈕點不到，搜尋框還會浮在內文上面。這是一行 CSS 撞名，很好修，建議先修再做別的。
2. **瀏覽器的「上一頁」會直接離開網站**。站內怎麼走都不會留下瀏覽紀錄，手機使用者習慣的返回手勢等於「關掉網站」。
3. **功能越加越多之後，入口太多、同一個東西有好幾個名字**。手機首頁要滑 20 個畫面；「謎題／單元／課」「專題／深入專題／主題標籤」「故事線／故事」混著用。這是逐項修補看不到的問題，建議整理一次首頁與用語。

## 三、這個網站是什麼（我的角度）

它其實是**同一批 435 張卡片的兩個外殼**：

- **學習模式**：給學生。用「謎題」把卡片包成 43 個單元，每個單元 12–13 步，有讀卡片、比較、決策、排序、史料、自我檢查。另外有故事線（讀長文）、深入專題（幾課＋勢力圖＋人物）、主題標籤（同一種東西跨時代）。
- **研究模式**：給老師或進階使用者。地圖＋卡片清單＋時間軸三塊並排，加上篩選、經濟曲線、物資鏈、今日對照、人群圖層、結構對照。

## 四、做得好的地方

1. **單元的教學設計很完整，而且在手機上能做完**。決策題先要你寫想法再給選項；排序題可以點、可以拖、可以用 ↑↓，對完答案能「只重排錯的」；答錯有解析，還有「回到卡片看」。中場休息畫面清楚說進度存好了。
2. **故事閱讀頁是全站最好的畫面**。手機字大小剛好；點內文地名會從下方滑出地圖，不會翻頁；地圖放大後按 Esc 只縮回地圖、不會關掉整頁；瀏覽器上一頁是關閉閱讀頁。桌機左文右圖也很舒服。
3. **效能很好**。處理器放慢 4 倍，手機首頁、卡片、專題長頁捲動都沒有超過 50ms 的畫格，版面位移 0；桌機時間軸縮放、拖曳沒有長任務。慢網路下首頁 1.9 秒可以點。全程 console 沒有網站自己的錯誤。
4. **研究模式的搜尋很耐打**。「罗马」會提示已轉成繁體、「羅碼」「雅片戰爭」「拿破侖」「napolean」都找得到，沒結果時會教你怎麼換關鍵字。
5. **底圖載不到時地圖還能用**。擋掉所有外部網站後，站內自己的疆域、地名、卡片圓點都還在（不過臺灣本島沒有海岸線，只剩地名）。

## 五、問題與建議

影響：高／中／低。工夫：大／中／小。

### A. 會擋住使用的 bug

#### A1. 手機、平板頁首壞掉：6 顆按鈕點不到，搜尋框蓋住內文
- **看到什麼**：頁首的小按鈕被拉成 101–129px 高的空白長條，頁首高度卻沒變，後面的按鈕和搜尋框被擠到頁首外面、壓在內文上。我用程式逐顆檢查能不能點到：
  - 手機：剛進首頁 7 顆都正常；點過「臺灣史」之後，「專題、#、🗺 我的地圖、📒 紀錄、Aa 字級、？說明」6 顆被內文蓋住點不到。回到首頁也一樣，要重新整理才會好。
  - 平板：「主題標籤、我的地圖、紀錄、A−、A＋、？」6 顆點不到。
  - 桌機：按鈕都點得到，只是變高（25px → 53px），頁首跟著變高。
  - 搜尋框浮在內文中間，蓋住卡片標題、專題進度條、「返回」鈕。切到「地圖」分頁時搜尋框整個被地圖蓋住。
- **在哪裡**：`?mode=learn&history=…`、`?mode=learn&unit=…`、`?mode=learn&card=…`、`?mode=learn&view=stories`，手機與平板。截圖 `key/1-mobile-header-broken.png`（左起：剛進首頁正常、XX史頁、單元封面、地圖分頁）、`key/2-tablet-header-and-map-buttons.png`、`z1-m-home-after.png`。
- **重現**：手機開首頁 → 按「知道了」→ 點「臺灣史」。頁首第二排變成空白長條；再點 📒 沒有反應。
- **原因（已在原始碼確認）**：`src/components/story-map.css` 第 2 行 `.sm { display:flex; flex-direction:column; height:100%; font-size:15px … }` 是故事地圖的外框，但全站小按鈕的 class 是 `btn sm`，所以這條規則套到每一顆小按鈕上。這個 CSS 檔在進到上面那些頁面時才載入，所以剛進首頁看不出來。這個檔最後一次改動是 c2fef56（2026-11-14），既有測試沒有抓到。
- **為什麼重要**：學生第一次點進任何一課就遇到；字級、紀錄、說明這幾個輔助功能在手機上等於消失。
- **建議**：把故事地圖的 class 改名（例如 `.smap`），或把選擇器改成 `.sr-side-map .sm` 這種有範圍的寫法。測試加一條：進過單元後，頁首每顆按鈕都要點得到。
- 影響：**高**　工夫：**小**

#### A2. 瀏覽器「上一頁」直接離開網站
- **看到什麼**：首頁 → XX史 → 單元 → 第 2 步 → 主題標籤 → 卡片，網址每一步都有變，但 `history.length` 一直是 2。在主題頁按瀏覽器上一頁，直接跳到 `about:blank`（進站之前的那一頁）。只有故事閱讀頁會多放一筆紀錄。
- **在哪裡**：學習模式全部，手機實測。記錄在 `a1.cjs`、`a2.cjs` 的輸出。
- **重現**：新分頁開首頁 → 點任一 XX史 → 點任一謎題 → 按瀏覽器上一頁。
- **為什麼重要**：手機使用者返回靠的是手勢或實體鍵，不是畫面上的「← 返回」。現在這個手勢會把人丟出網站。A1 又剛好把畫面上的「返回」蓋住一部分。
- **建議**：進入 XX史頁、單元、卡片、主題、專題、紀錄時用 `pushState`；單元內換步用 `replaceState`。站內的「← 返回」改成呼叫 `history.back()`，兩條路就會一致。
- 影響：**高**　工夫：**中**

#### A3. 搜尋框自己舉的例子搜不到
- **看到什麼**：學習模式搜尋框的提示是「想知道什麼？例：羅馬為什麼滅亡」。照著打「羅馬為什麼滅亡」，結果是「學習模式還沒有這個主題的卡片。可以到研究模式找找看，或試試下面的推薦謎題。」下面是空的，沒有推薦謎題。打「羅馬滅亡」或「羅馬」就有結果。另外打亂碼「asdfgh」不會說沒結果，而是出現「蘇聯入侵阿富汗」「九一一事件」兩張卡（大概是拼音近似比對到 Afghan，這是猜測）。
- **在哪裡**：`?mode=learn`，手機。截圖 `key/5-search-and-deadends.png` 左邊兩格。
- **為什麼重要**：提示在邀請學生用問句搜尋，但搜尋不懂問句。第一次嘗試就失敗，學生不會再用。
- **建議**：比對前先拿掉「為什麼、怎麼、是什麼、嗎」這類問句字，或拆成關鍵詞各自比對後合併。沒結果時真的列出 3 個推薦謎題。近似比對設門檻，太不像就說沒有。
- 影響：**中**　工夫：**小到中**

#### A4. 網路一斷，點一下就變成瀏覽器的錯誤頁
- **看到什麼**：首頁載好之後斷網，點「臺灣史」→ 整頁變成瀏覽器的「沒有網路」錯誤頁。單元已經開著、往後按了 3 步都正常（內容已下載），但切到「地圖」分頁 → 也變成錯誤頁。看起來是程式塊抓失敗後的「自動重新整理一次」在斷網時把還能用的畫面換掉了。網站沒有離線快取（沒有 service worker）。
- **在哪裡**：`?mode=learn`、`?mode=learn&unit=unit-taiwan-qing`，手機。腳本 `x3a.cjs`、`x3.cjs`。
- **為什麼重要**：學校 Wi-Fi 不穩很常見。學生做到一半只是想看一下地圖，畫面就沒了。進度有存，但他不知道。
- **建議**：自動重新整理之前先看 `navigator.onLine`。斷網時改顯示「現在沒有網路，這一塊還沒下載」和重試鈕，留在原畫面。進單元時順便把地圖、時間軸、卡片的程式塊先抓好。長期可以加離線快取。
- 影響：**中**　工夫：**小**（先擋自動重整）／**大**（離線快取）

### B. 資訊架構與複雜度

#### B1. 手機首頁太長，入口沒有主次
- **看到什麼**：手機首頁高 13,400px，約 20 個畫面，110 個可以點的東西。順序是：歡迎卡 → 17 個「XX史」→ 10 個深入專題（每個附一大段問題）→ 26 條故事線 → 8 個主題標籤 → 43 個謎題。43 個謎題排在最後，要滑過 60 多張卡才到。同一個內容出現很多次，例如古羅馬同時是 XX史、深入專題、兩條故事線、3 個謎題。有些 XX史很空（伊斯蘭世界史 0 個謎題，朝鮮半島史、印度史、占婆史、科技史各 1 個）。
- **在哪裡**：`?mode=learn`，手機。截圖 `key/3-mobile-home-length.png`、`02-home-m-strip0.png`、`02-home-m-strip1.png`。
- **為什麼重要**：歡迎卡說「選一個 XX史 → 挑一個謎題」，但頁面接著給了 5 種不同的入口，學生不知道哪個才是正路。
- **建議**：首頁只留三件事：(1) 接著做上次的；(2) 6–8 個精選謎題，可以用國中／高中或課本章節篩；(3) 四個入口卡「依地區（XX史）」「讀故事」「深入專題」「主題標籤」，各進自己的清單頁（這些清單頁現在都已經有了）。沒有謎題的 XX史先收起來。
- 影響：**高**　工夫：**中**

#### B2. 同一個東西有好幾個名字，不同東西名字又太像
- **看到什麼**（都是畫面上的原文）：
  - 「謎題」（首頁）＝「單元」（底部分頁、紀錄頁）＝「課」（專題裡「第 3／3 課」）＝「學習單元」（卡片上）。
  - 「專題」（頁首按鈕）＝「深入專題」；首頁 XX史區塊裡還有一組叫「專題（跨地區）」，指的卻是錢的歷史、科技史；頁首的「#」是「主題標籤」。專題、主題、主題標籤三個詞很像。
  - 「故事線」是一串站，「故事」是那篇長文，卡片裡還有一節也叫「📖 故事」。
  - 手機底部「單元」分頁其實裝了首頁、XX史、專題、主題標籤、我的地圖、紀錄。在主題頁點卡片會被帶到「卡片」分頁，那裡沒有返回鈕，要自己發現得點回「單元」分頁才有「← 返回」。「卡片」分頁沒開卡時只有一句「還沒打開任何卡片」，沒說去哪裡開。
- **在哪裡**：學習模式全部。截圖 `c3-strip.png`、`y1-strip.png`、`key/5-search-and-deadends.png` 第 3 格。
- **建議**：訂一張用語表並全站統一，例如單元一律叫「一課」，深入專題叫「大專題」，主題標籤叫「#標籤」。底部分頁改成「首頁｜正在讀｜地圖｜時間軸」，或讓卡片直接疊在同一個分頁上，返回鈕永遠在同一個位置。
- 影響：**高**　工夫：**中**（多半是改字和分頁邏輯）

#### B3. 兩個模式各有一套外殼，分享連結會進錯模式
- **看到什麼**：全新瀏覽器開 `?dive=dive-sengoku`（沒有 mode），網址變成 `?mode=research&dive=…`，進的是研究模式：手機上方先是 8 個類型篩選＋場域＋文明，專題放在「故事／主題」分頁。同一個專題用 `?mode=learn&dive=…` 開，是另一套頁首、另一組分頁、另一種區塊順序。學習模式的主題頁裡，有些卡片標著「研究模式 ↗」，點了會整個換到研究模式。
- **在哪裡**：`?dive=…`、`?story=…`，手機。截圖 `c1-strip.png`（研究模式外殼）對照 `c3-strip.png`（學習模式外殼）。
- **為什麼重要**：老師貼連結給學生，學生看到的可能是研究模式的介面。

- 影響：**中**　工夫：**中**

#### B4. 單元裡每張卡都是整張展開，「下一步」在 8 個畫面以後
- **看到什麼**：「讀卡片」那一步放的是整張卡：故事、史料、史家怎麼吵、今日對照、名詞小抄、從哪裡來、往哪裡去、在哪些故事裡。手機高 4,400–5,500px，「下一步」在最底下。這一課有 6 張這樣的卡，封面卻寫「預估 35 分鐘」。卡片中間還有「這張卡在這些故事裡」的上一站／下一站按鈕和主題標籤，一點就離開單元。桌機更擠：1366×768 預設三塊並排，讀的那一欄只有 727×440px，一張卡要捲 9 次以上；平板那一欄寬 435px。

### E. 無障礙

#### E1. 換步之後鍵盤焦點掉了，答題結果不會報讀
- **看到什麼**：用鍵盤在封面按 Enter 開始、或按 → 換步之後，焦點落在 `<body>`。學習模式的首頁、單元、卡片都沒有 `aria-live` 或 `role=status`（故事閱讀頁、專題、研究模式有）。所以答對答錯、「排對 2／5 個」螢幕閱讀器不會唸。
- **在哪裡**：`?mode=learn&unit=unit-rome-fall`，桌機鍵盤。11-08 的待辦有「『想好了』按鈕後的焦點」，這是同一類，範圍更大。
- **建議**：換步後把焦點移到這一步的標題（加 `tabindex=-1`）。回饋區加 `role=status`。
- 影響：中　工夫：小

#### E2. 學習模式沒有 h1，標題從 h2 開始
- **看到什麼**：首頁、單元、卡片、專題都沒有 h1（故事閱讀頁有）。研究模式的清單全部是 h4。
- **建議**：每頁的主標題用 h1；網站名稱在首頁以外不必是標題。
- 影響：低　工夫：小

#### E3. 鍵盤順序：先繞過頁首 12 顆和版面工具，才到內容
- **看到什麼**：桌機 Tab 順序是「跳到主要內容 → 品牌 → 模式 → 搜尋 → 3 個看不見的搜尋建議 → 🎲 → 6 顆頁首鈕 → A− A＋ ？→ 2 個分隔線 → 拖曳把手、浮動、新視窗 → 才到內容」。焦點框都有。「跳到主要內容」有用，但看不見的 3 個建議會讓焦點消失 3 次。
- **建議**：看不見的建議不要進 Tab 順序。
- 影響：低　工夫：小

對比：用程式算了 7 個畫面約 1,400 段文字，低於 4.5:1 的只有研究模式的紅字「紅線：」（4.06）和地圖英文小字（4.41），整體沒問題。

### F. 老師的需求

#### F1. 單元只能印「目前這一步」
- **看到什麼**：在單元第 2 步列印，4 頁 A4，只有那張卡。沒辦法印整課的題目當學習單。專題印出來 7 頁，按鈕都還在；研究模式的卡片列印把頁首、篩選、空白地圖一起印出來。故事閱讀頁（6 頁）和學習紀錄（2 頁、沒有按鈕）印得不錯。
- **在哪裡**：`x2-print-*.pdf`、`x2-print-strip.png`。
- **建議**：單元封面加「🖨 印學習單」：謎題、學完你會、每一步的引導問題、比較表、決策題、排序題（打散）、史料、自我檢查，附作答空格，不含答案；另一顆「印解答」。研究模式卡片列印時藏掉頁首、地圖、時間軸。
- 影響：中　工夫：中

#### F2. 進度只存在這台瀏覽器
- **看到什麼**：進度存在 localStorage 的 `history-river-learn-v1`。紀錄頁有誠實說明，可以列印或複製成文字，但沒有備份或搬到另一台的方法。學校共用電腦、手機清快取、無痕模式都會歸零；同一台電腦下一節課的學生會接到上一位的進度。
- **建議**（不必做帳號）：(1) 紀錄頁加「匯出／匯入進度」，用檔案或一串代碼；(2) 首頁「上次做到一半」旁加「這不是我 → 清除並重新開始」；(3) 「複製成文字」加上日期和每課實際做的步數，方便老師收。
- 影響：中　工夫：小到中

#### F3. 找不到「這一課對應課本哪裡、適合國中還是高中」
- 舊待辦（11-08、11-11 都列了 108 課綱與 level 欄位，還沒做）。這次以老師身分找課時，首頁 43 個謎題只能一個一個看，沒有年級或課綱可以篩。建議至少先標「國中／高中」。
- 影響：中　工夫：中（代碼要人工對照）
