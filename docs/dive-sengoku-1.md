12 張卡全部 `crosscheck: 通過`，都進入學習模式。查核者改了什麼（節錄，完整在各卡 crosscheck.notes）：

- **引文**：《信長公記》桶狹間暴雨句 5 處找不到逐字出處 → 改引可確認的「運の末には、知恵の鏡も曇る」；「是非に及ばず」字句與轉引來源一致，但原典影像（NDL 1881 刊本卷之上）不含本能寺條，改標「未對照原典」。《鐵炮記》補琉球大學藏 1649 年《南浦文集》影像為一手來源。伴天連追放令引文改為英譯頁面真的有的一句。
- **數字**：山崎之戰兵力「羽柴 2 萬餘（谷口克廣）」在所列來源查不到 → 改為日維約 4 萬／英維 2 萬–3.6 萬並列標「來源不足」；關原改易 87／82／93／88 家、沒收 500–680 萬石全部並列標估計；大坂夏之陣兵力三說並列；中國大返還改「200–230 公里、7–10 天」。
- **說法**：長篠卡刪德富蘇峰、名和弓雄、「1903 年」（來源查不到）；桶狹間 A7 毛利／服部取首與英維相反 → 並列存疑；關原小早川倒戈的藤本正行、呉座勇一之說查不到 → 改依白峰旬與 Turnbull；家康 1614 年「三選項」依曾根勇二改為片桐且元私案；秀吉「小時候乞討」改《太閤素性記》賣針流浪；秀吉 P6「海外雄飛」補中野等 2014 文獻目錄並改用具體書名。
- **來源層級**：3 筆被降級（OSU 大學部論文、京都先端科學大學學生論文、每日新聞轉述），每張卡仍至少 1 筆一手或學術。
- **座標**：長篠城改依英維條目（原偏 0.5 km）；其餘抽查 14 處誤差 <1 km。
- **勢力圖**：北條的上總、安房 1582 年實為里見領地（縣界切不開，暫併入並註明）；上杉的佐渡仍是本間氏；長宗我部的阿波仍有十河存保、伊予中部河野氏未降；伊達範圍過寬補註蘆名、相馬、大崎・葛西。只改說明文字，未改多邊形。

## 四、已知限制與第 2 期清單

**第 1 期沒做（依計畫留到第 2 期）**：其餘 31 張卡（毛利、武田、上杉、島津、北條、伊達、一向一揆、南蠻貿易、石見銀山與明朝白銀、琉球、臺灣關聯…）、4 個學習單元與決策題、1560／1570／1590／1600／1615 勢力圖、人物關係網圖、`pop_culture`（戲劇 vs 史實獨立區塊，目前先寫在 misconceptions）、公有領域肖像圖片、專題頁的學習模式版。

**查核者留下的待辦**：

1. 原典字句：《信長公記》本能寺條、《應仁記》和歌卷次、《本光国師日記》遺言，都只對到二手轉錄；需 NDL 掃描或校注本。
2. 單一來源的數字：肥前刀狩 16,000 把（佛洛伊斯轉引）、一國一城令「400 座／3,000→170」、長篠「家康約 8 千」、毛利減封 36.9 萬石之說。
3. 未決：光秀受封丹波 1578／55 萬石（英維）vs 1580／34 萬石（日維）；桶狹間國史跡指定年份；家康死因與「狸親父」起源。
4. 座標：設樂原、鳶巢山、西之表、堺、國友仍是依地名估的 schematic（地理編碼服務被代理擋下）。
5. 勢力圖：要正確畫出里見、河野、蘆名需要支援緯度切分或更細的底圖多邊形。

**技術限制**：勢力圖以今日縣界近似令制國，邊界只是示意；學習模式的地圖目前只標人物地點，尚未畫人生軌跡虛線；家康卡沒寫 relations（由信長、秀吉卡的關係涵蓋）。

## 五、怎麼複製到下一個專題

見 `docs/dives.md` 第五節。簡述：先決定年代與大問題 → 盤點既有卡、列 10–12 張最小版 → 作者寫、獨立查核 → 寫 `data/dives/<名>.yaml` → 需要時寫勢力圖 → `npm run validate`、`npm run build:index`、`node scripts/qa/dive.cjs`。經濟類專題（例如日本失落 30 年）不做勢力圖，主視覺用經濟曲線。
