# 各區塊大小可自行調整（2026-10-26）

網站：https://zlo-25.github.io/Long-History/

## 我理解的目標

桌機上看網站的人（學生、老師、ZL 自己）螢幕大小和需求都不同：有人想把地圖放大看路線，有人想把文字欄拉寬讀故事，有人根本不想看時間軸。
原本各區塊的比例是寫死的，只能照設計者的安排看。這次要讓每個人自己拖出合適的版面，網站記住它，想復原也一鍵回來。
前提是不能改壞已經在用的功能（網址參數、單元、模擬、時間軸）。

## 做了什麼

```
 研究模式（桌機）                         學習模式（桌機）
 ┌────────────────┬─╂─┬──────────┐      ┌──────────┬─╂─┬────────────┐
 │                │ ┃ │ 卡片清單  │      │ 文字欄    │ ┃ │   地圖     │
 │     地圖        │ ┃ │ ／卡片   │      │（單元、卡片）│ ┃ │           │
 │                │ ┃ │          │      │          │ ┃ │           │
 ├━━━━━━━━━━━━━━━━┷━━━┷━━━━━━━━━━┤      ├━━━━━━━━━━┷━━━┷━━━━━━━━━━━━┤
 │ 時間軸（可拖高、可收起）  ▾收起時間軸 │      │ 時間軸（可拖高、可收起）  ▾收起時間軸 │
 └───────────────────────────────┘      └───────────────────────────┘
   ┃ ━ ＝ 可拖曳的分隔線（左右拖調寬、上下拖調高）
```

| 操作 | 效果 |
|---|---|
| 滑鼠／觸控拖分隔線 | 該區塊即時變大變小，地圖同步重新量尺寸不留白 |
| 連點兩下分隔線 | 這一條恢復預設 |
| 鍵盤：Tab 到分隔線，← → 或 ↑ ↓ | 每按一下 24px；Home／End 恢復預設（給不用滑鼠的人） |
| 表頭「⟲ 版面」 | 只有調過版面才出現；按一下全部恢復預設 |
| 研究模式「▾ 收起時間軸」 | 新增，和學習模式一樣；收起後地圖佔滿高度 |
| 重新整理、下次再來 | 記在這台瀏覽器（localStorage `history-river-layout-v1`），研究、學習模式各自記 |
| 視窗縮小 | 存的尺寸永遠夾在合理範圍內（欄寬 280px～65%、時間軸 60px～55%），另一邊不會被擠到看不見 |
| 手機 | 沒有分隔線，維持原本的分頁切換 |
| 列印 | 分隔線不印出來 |

## 順便評估的其他易用性改善

這次一併做了：研究模式時間軸可收起（原本只有學習模式有）、分隔線可用鍵盤、地圖改大小不留白。
看過但沒動（和「學習者改善第二輪」重疊或需要 ZL 決定）：

1. **分隔線第一次不容易被發現**：目前靠滑過去游標變形＋提示文字。可以在第一次進站時閃一下分隔線，或在「？」說明加一句。
2. **研究模式右欄在 1366 寬螢幕預設 34% 略窄**：現在可以自己拉寬，所以先不改預設。
3. **版面設定只記在這台瀏覽器**：換電腦要重拉。和學習進度一樣是刻意不做帳號系統。
