# 讀史方法：參考呂世浩老師的教學主張（2026-11-01）

> 本檔說明學習模式裡「先掩卷自思 → 對照古人 → 回到自己」這三個設計從哪裡來，以及**哪些話是呂世浩老師直接說的、哪些是本站自己的整理**。之後任何地方要引用呂老師，都照本檔第三節的邊界寫。

## 一、他公開說過什麼（直接談到）

| 主張 | 原話或轉述 | 來源 |

| 對照古人與自己的衝動 | 轉引清代左宗棠：設想「設若古人當此，其措置之法，當是如何？我自己任性為之，又當如何？」 | 同上 |

## 二、本站怎麼把它做進學習模式（本站推論）

```
讀卡片、讀史料
      │
      ▼
決策步驟 ─► ① 先別看選項，寫下「如果我是他，只知道這些，我會怎麼做」   ← 掩卷自思（呂祖謙）
      │
      ▼
      ② 選一個 → 看結果 → 看歷史上實際發生的
      │
      ▼
      ③ 對照一下：當時的資訊與壓力？我的直覺和他差在哪？代價誰付？     ← 古人怎麼做 vs. 我任性為之（左宗棠）
      │
      ▼
回顧步驟 ─► ④ 回答謎題（參考說法「不是標準答案」）                       ← 沒有標準答案
      │
      ▼
      ⑤ 🪞 回到自己：每個單元一題反思（欄位 reflect）                    ← 書本與處事不分兩事
```

- 學習首頁有「📜 為什麼要學歷史？」說明框，把上面濃縮成「先有問題、把自己放進去、看成敗也看代價、回到自己」四步，並明寫「整理成四步是本站自己的設計，不代表呂老師本人的課程安排」。
- 「盛的時候找衰的種子」是本站對「稽其興壞成敗之理」（《史記‧太史公自序》語，呂老師在課程介紹中引用）的白話延伸，不是呂老師原句。
- 寫的東西只存在學生自己的瀏覽器，不評分。

## 三、引用邊界（之後寫卡片、單元一律遵守）

1. **只引有公開來源的話**，並附連結。找不到來源，就不要說「呂世浩認為」。
2. **分清楚「直接談到」和「本站推論」**：呂老師談秦始皇、張良、《史記》有公開課程；他沒談過的事件（例如臺灣史、近代金融），不能寫成他的看法，只能寫「本站借用這個讀史方法來讀」。
3. **轉引要說是轉引**：呂祖謙、左宗棠的話是呂老師在〈《史記》中的智慧〉一文中引用的，要寫「他引宋代呂祖謙」；「稽其興壞成敗之理」是司馬遷語，同樣要標明。
4. **不替他下結論**：單元的反思題是開放問題，不放新史實，也不暗示「呂老師會這樣回答」。
5. 另一個執行緒（融入呂世浩觀點的歷史啟發）若要把他對三國、秦漢個別事件的解讀放進卡片，同樣照本節寫，並在 sources 標 tier（課程、演講紀錄多屬「摘要」或「通論」，他的學術論文屬「學術」）。

## 四、每個單元的「回到自己」題怎麼寫

- 從單元裡的**某個真實選擇**出發（例如 1720 年倫敦投資人要不要再進場），轉成學生生活裡的同型處境（大家都在做時要不要跟）。
- 只問、不教訓；不用「應該」。
- 不放卡片沒有的史實；`npm run validate` 會在 reflect 出現 `[s1]` 代號時警告，缺 reflect 時也會提醒。
