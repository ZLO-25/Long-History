# 教學學者視角的內容檢視（2026-10-26）

> 目的：以「歷史教學／歷史教育」的角度，檢視本站 126 張卡、9 個學習單元，評估知識完整度、卡片之間的關聯、能否讓學生理解更深刻、還有哪些案例值得整合，然後直接補強。本檔記錄評估結果與實際改動。

## 一、評估方法

```
108 課綱（國中臺灣史／東亞史／世界史，高中歷史）必修主題
        │ 逐一對照
        ▼
現有 126 張卡 ──► 哪些主題沒有卡？哪些有卡但沒進學習模式？
        │
        ▼
卡片關聯圖（links / counterparts / 單元 next）──► 哪些卡是孤島（links ≤ 1）？
        │
        ▼
學習單元 9 個 ──► 哪條史有卡卻沒有單元？單元之間能不能連成一條「學習路徑」？
```

## 二、評估發現

### 1. 知識完整度：臺灣史有一個兩百多年的洞

對照 108 課綱國中臺灣史的分期，補強前的卡片分布：

```
史前      荷西       明鄭        清領 (1683–1895)      日治 (1895–1945)     戰後 (1945– )
  0        3          1              0                      0              8（全部是錢／產業）
                                 ▲▲▲▲▲▲▲▲▲▲           ▲▲▲▲▲▲▲▲▲
                                 212 年沒有任何一張卡    50 年沒有任何一張卡
```

- 清領（渡臺禁令、移墾與械鬥、開港通商、牡丹社事件、建省）與日治（乙未割臺、文化協會、霧社事件、皇民化）完全沒有卡，而這兩段正是國中臺灣史的重心。
- 戰後 8 張卡全部是金融與產業（新臺幣、股市、加工出口區、晶片），**政治史一張都沒有**：二二八、戒嚴與白色恐怖、土地改革、民主化都缺。學生從本站看到的戰後臺灣只有「經濟奇蹟」，沒有「為什麼能投票」。
- 世界史方面：伊斯蘭世界只有 1 張（十字軍）、印度 1 張、東南亞 2 張；工業革命只有技術卡沒有「事件卡」；美國獨立、啟蒙運動、冷戰起點、殖民帝國主義都沒有。這些是下一輪的候選，本輪先補臺灣史（本站的核心讀者）。

### 2. 關聯度：有 14 張卡是「孤島」

- `links` 為 0 或 1 的卡有 14 張（例如城濮之戰 0、黑死病 0、赤壁 1、十字軍 1、鄭和下西洋 1、西拉雅與鹿 1、十大建設 1）。學習卡頁面的「延伸」區只會列出 links／backlinks／counterparts，孤島卡的學生讀完就斷了。
- 臺灣戰後卡之間只靠「錢」串連（新臺幣 → 股市），沒有「政治 → 經濟」的連線：土地改革和加工出口區、民主化和十信案之間沒有關係可點。
- 單元之間的 `next` 只在同一主題內跳（臺灣 → 臺灣、錢 → 錢），沒有「跨史」的連結（例如荷治臺灣 ↔ 阿姆斯特丹交易所已經有 counterparts，但單元層沒有）。

### 3. 理解深度：結構已經很好，缺的是「長時段」與「爭議」

- 單元的 9 種步驟（謎題 → 讀卡 → 史料判讀 → 因果鏈 → 比較 → 決策 → 今日類比 → 小測驗 → 回顧）符合歷史思維教學（historical thinking）的主張：證據、因果、觀點、變遷與延續。這部分不必改。
- 但「變遷與延續」在單元層只跨幾十年。臺灣史最值得教的長時段問題（例如「同一座島被五個政權統治，每個政權都在做什麼？」「原住民族的處境怎麼一路變？」）沒有單元能承載，因為卡片不夠。
- 「史家怎麼吵」（historiography）在學習卡裡已經有，但以臺灣史來說最有教學價值的爭議（二二八死亡人數怎麼估、土地改革到底誰受益、霧社事件是「抗日」還是「部落對殖民統治的反抗」）都還沒進來。

## 三、實際改動

1. **新增 10 張臺灣史卡**（上表），全部有學習區塊、一手或學術來源、獨立查核通過，臺灣史學習卡從 14 張變成 24 張，時間軸上 1683–1945 不再是空白。
2. **新增 3 個學習單元**，和既有 3 個臺灣單元接成一條從 1624 到 1996 的學習路徑：

```
unit-formosa-wanted ──► unit-taiwan-qing ──► unit-taiwan-colony ──► unit-taiwan-democracy
 (1624 荷西明鄭)        (1684 清領兩百年)     (1895 日本時代)         (1947 戰後到投票)
                                                                        │
                                           unit-taiwan-currency-1949 ◄──┤
                                           unit-chip-island          ◄──┘
```

3. **補關聯**：14 張孤島卡各補 2–3 個 links；既有臺灣卡（明鄭、新臺幣、加工出口區、十大建設、自強運動、鴉片戰爭）補上指向新卡的連線；既有臺灣單元的 `next` 改成接到新單元。
4. **文明分類樹**補上 `臺灣（清治）`，篩選面板可以只看清領時期。
