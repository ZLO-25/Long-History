# 第 6 期驗收回報：學習模式（給國高中生自學）

日期：2026-10-25

## 一、這一期在解決什麼問題

原本的歷史長河是 ZL 自己用的研究工具：先要知道想找什麼，才找得到東西。國高中生打開它，不知道從哪裡開始，卡片的文字也太難。

這一期另外做了一個**學習模式**給國高中生用，研究模式完全不動：

```
研究模式（給 ZL）              學習模式（給國高中生）
─────────────────              ─────────────────────
自己搜尋、勾條件               先選一條「XX史」，再挑一個「謎題」
卡片一次全部展開               卡片分三層：故事 → 理解 → 深入
看資料、自己判斷               一步一步帶：讀史料、排因果、比一比、你會怎麼選、小測驗
                               每一步都有 2–3 段提示，答錯可以跳回卡片原文
網址參數照舊                   網址：?mode=learn&history=…&unit=…
```

💰＝談錢的單元（3 個，要求是至少 2 個）。

每個單元的步驟大致是：

```
開場比喻 → 讀 2–5 張卡 → 讀一手史料（選擇題）→ 排因果鏈 → 兩張卡比一比
        → 「如果你是……」決策（沒發生的選項都標「推測」）→ 今天能不能這樣類比
        → 小測驗（選擇、排序、簡答）→ 回顧謎題 → 接下來可以挖
```

## 三、查證怎麼做的

```
寫卡（寫作 agent）
   │  每一句附來源；估計值標「估計」；有爭議就並列；查不到寫「來源不足」
   ▼
獨立查核（另一個沒參與寫作的 agent）
   │  每個關鍵事實至少 2 個彼此獨立的來源；一手史料逐字對照原文或譯本
   │
   ├─ 不通過 ──► 照查核者給的修正文字改 ──► 再查一次
   └─ 通過 ────► 寫進卡片的 crosscheck 欄位 ──► 才會出現在學習模式
```

查核實際抓到並修掉的錯誤舉例（這些都是改完、再查一次才通過的）：

- 柏南奇 2007 年的引文被刪掉主詞，意思從「對整體經濟的**影響**會被控制住」變成「**問題**會被控制住」。
- 卡拉卡拉敕令卡寫「新公民大多不富裕」，兩個來源都沒有這樣說，已刪掉。
- 「沃德－帕金斯說轉型論『不只是錯的，也是危險的』」，來源裡找不到這句話，已改成來源裡真的有的說法。
- 威瑪卡把 1922 年的「金馬克比值」當成美元匯率，已改正。
- 鄭和寶船 127 公尺，原本只說出自明代小說，漏了清修《明史》也有記載，已補上。
- 王莽卡兩句話標錯來源，「28 種／37 種貨幣」也補上兩個數字各指什麼。
- 布列敦森林協定第 4 條的引文截斷，漏掉「或以美元表示」，已補全。
- 單元方面：「羅馬城人口半世紀少了一半」誇大（卡片是 70–80 萬降到 40–50 萬），已改成卡片數字。

來源分級統計（126 張卡）：一手 44、學術 62、通論 85、摘要 41、百科 121。學習模式的卡每張至少有 1 個「一手」或「學術」來源。

## 七、補做：經濟曲線延伸到 2022 年（F4）

ZL 下載了 3 份資料，接著做完了經濟曲線。研究模式的時間軸上方原本只有西元 1 年前後的數字，現在一路畫到今天：

```
經濟曲線的按鈕
  人口、人均 GDP ──── Maddison 2023：西元 1 年 → 1000 → … → 2022（中、日、臺、英、荷、義、印、美）
  實質工資 ────────── Clio Infra：1820–2008，「一天工資買得到幾籃最低生活必需品」
  英格蘭名目日薪 ──┐
  英國物價 ────────┼─ 英格蘭銀行千年資料：1209–2016
  英國實質工資 ────┘   名目、物價、實質三條分開，不畫在同一條軸上
```

可以拿來教的例子：1500 到 1600 年，英格蘭工人的日薪漲了一倍多，物價卻漲了約 4 倍，所以實質工資反而掉了約四成。這就是「加薪不等於變有錢」。

- **怎麼做的**：用腳本直接從下載檔讀數字，每十年畫「最低到最高」的範圍，不平均、不內插。人均 GDP 和新指標都用對數刻度。
- **查核**：另開一個查核 agent 逐點對照原檔，634 個點 0 個錯誤。說明文字照查核意見改過，包括 Maddison 規定的各國原始研究、生活必需品籃子的內容、資料品質評等、臺灣缺的年份。
- **授權**：Maddison 2023 是 CC BY 4.0；Clio Infra 是 CC0，但查核時網頁擋了自動讀取，沒能再確認一次；英格蘭銀行資料依 Open Government Licence，其中第三方資料（例如 Clark 的工資）版權屬原作者。
- **限制**：手機版研究模式本來就沒有時間軸，所以經濟曲線只在桌機寬度看得到。
