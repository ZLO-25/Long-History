# 三個區塊：拖曳換位置、浮動小窗、新視窗（2026-11-02）

網站：https://zlo-25.github.io/Long-History/

## 我理解的目標

桌機畫面分三塊（研究模式：地圖／卡片欄／時間軸；學習模式：文字欄／地圖／時間軸）。
ZL 希望每個人都能自己擺：把區塊換位置（A）、變成頁面裡可自由拖動的浮動小窗（C），
或拉出成另一個瀏覽器視窗（例如放第二個螢幕），而且一顆按鍵就能全部復原。
條件：拉出去的視窗資料要和主視窗連動、要測試、不能拖慢網站；手機維持原本分頁。

## 怎麼用

```
 每個區塊上方多一條標題列：
 ┌──────────────────────────────────────────┐
 │ ⠿ 地圖                     ▣ 浮動  ⧉ 新視窗 │ ← 抓「⠿ 地圖」拖到別的區塊上 → 兩塊交換位置
 ├──────────────────────────────────────────┤
 │                 （原本的地圖）               │
 └──────────────────────────────────────────┘

 三種狀態，可來回切換：
   停在格線 ──▣ 浮動──▶ 頁面裡的浮動小窗 ──⧉ 新視窗──▶ 另一個瀏覽器視窗
            ◀──⊟ 放回──                  ◀──↩ 放回主視窗／直接關掉視窗──
```

| 操作 | 效果 |
|---|---|
| 拖「⠿ 名稱」到另一個區塊上放開 | 兩個區塊交換位置（拖曳時目標會出現「放開：交換位置」） |
| 鍵盤：Tab 到「⠿ 名稱」，按 ← → | 和前一個／下一個位置交換（給不用滑鼠的人） |
| ▣ 浮動 | 變成浮動小窗，拖標題列移動、拖右下角改大小；其他區塊自動補滿空位 |
| ⊟ 放回 | 浮動小窗回到原本位置 |
| ⧉ 新視窗 | 拉出成新的瀏覽器視窗；主視窗表頭出現「↩ 收回○○」 |
| 關掉新視窗 | 該區塊自動回到主視窗 |
| ⟲ 版面 | 大小、位置、浮動小窗、新視窗全部恢復預設（新視窗會被關掉） |
| 重新整理 | 位置與浮動小窗會記住（localStorage `history-river-layout-v1`）；新視窗不記（瀏覽器規定新視窗只能由點擊開啟） |
| 手機 | 沒有標題列，維持原本分頁切換 |

## 資料怎麼連動、為什麼不會變慢

```
            同一份狀態（年份、選中的卡、篩選、主題…）
                         │
          ┌──────────────┼──────────────────┐
          ▼              ▼                  ▼
     主視窗的區塊     浮動小窗（同一個 DOM，    新視窗（React portal：
                      只是改成 position:absolute） 同一棵 React 樹畫進另一個視窗）
```

* 不是「複製一份網站到新視窗再互相傳訊息」，而是同一個程式直接畫到新視窗裡，所以不會有不同步的問題，也不用多載一次資料。
* 浮動小窗拖動、改大小時直接改 CSS 位置，不觸發 React 重畫；放開滑鼠才存一次。
* 新視窗打開時先等樣式表載完才畫地圖（否則 Leaflet 量到 0 高）。
* Leaflet 拖曳地圖時是聽主視窗的滑鼠事件，所以新視窗會把滑鼠事件轉給主視窗，地圖在新視窗也拖得動。
* 限制：新視窗的地圖動畫由主視窗驅動，若把主視窗最小化，瀏覽器會暫停它，新視窗地圖會停止更新；主視窗放在背後（沒最小化）沒問題。
