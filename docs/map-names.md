# 地圖名稱改成「繁體中文＋英文」

## 要解決的問題

原本的底圖是 OpenStreetMap 標準圖磚，地名用的是各國當地文字（波蘭文、俄文、希臘文、阿拉伯文……），學生看不懂。
這次把地圖上**所有看得到的名稱**都改成「繁體中文＋英文」。

## 做法

底圖本身換成「不帶任何文字」的版本，地名全部由我們自己畫上去：

```
┌──────────────────────────────── 地圖由下往上疊 ────────────────────────────────┐
│ 5. 提示框（滑過才出現）  案例地點／路線／站點／疆域政權／今日咽喉 → 中文＋英文      │
│ 4. 本站圖層              案例圓點、道路航線、物資鏈、今日咽喉（標記上的字也中英）    │
│ 3. 地名層（新）          國家、城市、海洋、山脈沙漠、河流 → 中文＋英文              │
│ 2. 古代疆域              historical-basemaps（政權名稱補上中文）                    │
│ 1. 底圖（新）            OpenFreeMap 向量圖磚，文字圖層全部拿掉                     │
└──────────────────────────────────────────────────────────────────────────────┘
```

為什麼不直接換一個「有中文地名」的現成底圖？

| 選項 | 問題 |
|---|---|
| 現成底圖的中文版（OSM 的 name:zh 等） | 很多地名只有簡體或沒有中文，同一張圖會混著簡體、繁體、當地文字；沒辦法統一用臺灣譯名 |
| CARTO 無字底圖 | 2026-09-25 起點陣圖磚要申請 API 金鑰，公開網站不適合把金鑰放在前端 |
| Esri 底圖 | 舊的免金鑰服務已停用，新版要帳號 |
| **OpenFreeMap 無字向量底圖＋自己畫地名（採用）** | 免金鑰、無流量上限、可商用；地名用公有領域的 Natural Earth，譯名可以完全照臺灣用法 |

## 資料檔

| 檔案 | 內容 | 怎麼改 |
|---|---|---|
| `data/labels/basemap-labels.json` | 地圖上的地名（國家 241、城市約 2,500、海洋 111、地形區約 400、河流 47、自訂 12） | 不要手改；改完 overrides 後執行 `npm run labels` |
| `data/labels/basemap-overrides.yaml` | 臺灣慣用譯名（例：紐西蘭、印尼、麻六甲海峽、裏海）、要跳過的地名、哪一級縮放開始出現、河流清單、自訂地名（黎凡特、關中平原、博斯普魯斯海峽……） | 直接改 |
| `data/labels/names-en.yaml` | 本站卡片地點、路線站點、物資鏈、今日對照層的中英對照（中文→英文、拉丁文→中文） | 新增卡片時補上；`npm run build:index` 會列出還缺英文的地名 |
| `data/labels/polities-zh.yaml` | 古代疆域約 1,200 個政權名稱的中文 | 直接改；沒列到的小族群會依位置標「澳洲原住民族群」「北美原住民族群」 |
| `src/lib/basemap-style.json` | 底圖樣式（OpenFreeMap Liberty 去掉文字圖層） | 一般不用改 |

`npm run labels` 需要網路下載 Natural Earth；如果已經下載到某個資料夾，可以用 `NE_DIR=資料夾 npm run labels`。

## 地名怎麼排

- 每個地名有「從第幾級縮放開始出現」：世界圖只看到洲、大洋、大國；放大到地中海看到海、島、大城市；再放大才有小城市。
- 同一個畫面裡，重要的先放（海洋→國家→首都→地形→河流→城市），會跟已放好的字重疊的就不畫。
- 地名是灰褐色、白色描邊，比本站的彩色案例圓點淡，避免搶走重點。圖例加了一句「地名：中文＋英文（灰字＝今天的國家、城市）」。

## 備援

瀏覽器不支援 WebGL（極少數舊電腦）或底圖程式載入失敗時，會退回原本的 OpenStreetMap 點陣圖磚。這時底圖上的字會是當地文字，但我們自己畫的中英地名層仍然疊在上面。

## 測試

- `node scripts/qa/labels.cjs http://localhost:4173/`（新）：底圖地名都有中文和英文、放大後出現城市、案例地點／疆域提示框中英並列、卡片地點有英文、今日咽喉標記中英並列、學習模式也有地名。
- 既有的 `research.cjs`、`layout.cjs`、`overlap.cjs`、`e2e.cjs` 全部通過。
- `docs/screenshots/map-names/` 的截圖是在開發容器裡拍的。容器連不到 OpenFreeMap，所以截圖裡的底圖是用 Natural Earth 自製的測試圖磚（只有海、湖、國界、河流）。正式網站上會有完整的道路、地形和土地利用顏色，地名層則和截圖一樣。
