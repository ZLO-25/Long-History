## 二、驗收

- `npm run validate`：99 張卡、0 錯誤、0 警告。
- `npm run typecheck`、`npm run build`：通過。
- 實際打開（開發伺服器，1440 寬）：文明樹狀篩選可展開、點「西漢」只剩 12 張；「現代」跳轉後四條軌都在畫面內；網址 `?card=` 直接開技術卡、金融卡正常，年代會跳到該卡。
- 過程中修掉的問題：
  - 卡片別名寫純數字（12682）會被 YAML 讀成數字，讓搜尋建索引當掉、整頁白屏。已改成建索引時一律轉字串，validate 也會警告。
  - 網址直接開卡時年代停在前 490 年，現在會跳到該卡年份。
  - 視窗寬度改變後時間軸會跑到別的年代，現在會重新對準所選時代。
