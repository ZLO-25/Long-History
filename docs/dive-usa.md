# 美國崛起深入專題（第 3 期）驗收回報

第二個專題，用**既有的美國史卡片**組成（37 張，沒有寫新卡、沒有改卡片內容），目的是證明專題模板沒有為日本戰國寫死。網址：`?dive=dive-usa`（研究模式）、`?mode=learn&dive=dive-usa`（學習模式），或頂端「專題」按鈕。

## 一、做了什麼

| 項目 | 內容 |

## 二、領土圖怎麼畫

### 年份為什麼是這五個
|---|---|

## 四、已知限制

- 美國底圖只有今日美國 50 州與華府：英屬北美、墨西哥本土不畫；波多黎各、關島、菲律賓（1898 年取得）不在圖上，由 `note` 文字與「美西戰爭」卡交代。
- 以州為單位近似，切線是經線或緯線，不是當時的實際界線；原住民族的土地與實際控制範圍畫不出來，`power_ui.caveat` 與「西進擴張」卡的「代價」交代。
- 1898 年圖的夏威夷在縮小時只有幾個像素；阿拉斯加在視野之外（`view` 只到北緯 50°），放大地圖才看得到。
