## 4. 已知問題與限制

1. **道路與航線是示意線**：用主要城市點位直線相連，不是實際路面。精細的 Itiner-e 羅馬道路資料（78 MB）在雲端環境下載不到，已寫好 `npm run roads`，你在自己電腦執行一次就會出現細線道路。
2. **疆域是示意**：historical-basemaps 是粗略年代快照（GPL-3.0），邊界與年份都不精確，地圖上已標「疆界示意」。年份對應規則是「取不晚於目前年份的最近一張快照」。
3. **底圖需要網路**：OpenStreetMap 底圖要連網才看得到；離線時只有疆域與點線。
4. **程式包偏大（約 1.8 MB）**：主要是簡繁轉換字典。本機使用沒有影響。
5. **時間軸在最左邊（前 800–前 600）沒有卡**，所以那段被壓得很窄，這是非線性設計的預期結果。
6. 中國錨點 3 張是**摘要卡**，只要求核心欄位，完整度 88%。
