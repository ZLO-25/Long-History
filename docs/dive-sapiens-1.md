# 深入專題《人類大歷史》第 1 期報告（2026-11-07）

使用者需求：「把人類大歷史這本書的內容與脈絡，結合這個網站呈現，可以作為專題。」ZL 選「照建議」：
骨架照書的章節、每站標題寫成問題；只標章節、不標頁碼、不引原文；第 19、20 章做成討論題、不補卡。

```
 ?dive=dive-sapiens
 ┌ 深時間軸（250 萬年前 → 今天，距今年數取對數；四部＝四個色塊）
 ├ 照書讀：20 站（每站：④先想一想 → ①書裡怎麼說 → ②歷史證據卡 → ③另一種看法）
 ├ 這段時代的卡片（53 張：8 張新卡＋45 張各章證據卡）
 └ 來源清單 b1–b38
```

## 做了什麼
- **讀書專題格式**（docs/dives.md 第七節）：`data/dives/sapiens.yaml` 的 `book`（parts／chapters／sources）、`focus_year`；validate 檢查每站 claim 有 [bN] 且來源存在。
- **畫面**：`src/components/DiveBook.tsx`（DeepTimeline、BookView）；先想一想按「想好了」才展開；來源上標點了打開來源清單（不改網址）。
- **史前卡不擠在時間軸左端**：大時間軸與學習模式時間軸把整張卡早於前 800 年的卡拿出軸外，改成「◂ 史前 N」按鈕，點了打開本專題。
- **年份**：早於前 1 萬年顯示「約 X 萬年前」。**地圖**：比最早疆域快照早 200 年以上不畫疆域，標「還沒有國家」。
- **8 張新卡**（各 6–10 個來源，兩位作者撰寫、兩位未參與寫作的查核者逐項核對，全部通過）：
  人屬的多個物種、認知革命、走出非洲與抵達澳洲、大型動物滅絕、人類抵達美洲、肥沃月彎的農業革命、哥貝克力石陣、東亞的稻與粟。
- **20 站內容**：作者依 LitCharts 各章摘要、SuperSummary、Wikipedia 撰寫；查核者修正 9 章（例：紐西蘭「約 800 年前才登島」不是「800 年內」；採集者每週 35–45 小時；黑猩猩群體數字張冠李戴；Strawson、Hallpike、Narayanan 的說法照原文改寫）。
- 文明分類新增「史前／史前人類」；33 個史前地名補英文。

## 限制（誠實交代）
- 沒有對照實體書，「書裡怎麼說」根據公開摘要；LitCharts 部分章節有付費遮罩，第 12、17 章查核時額度用完、沒能逐字核對。
- 第 7–10、13–15、17、19 章還沒有「另一種看法」（第 2 期補）。
- 不少學術論文頁（nature、science、pnas）容器打不開，改用摘要頁或維基轉述，卡片的 crosscheck.notes 有逐項寫明。
- WebFetch 全 session 每小時約 100 次共用，本期用了約 250 次。
