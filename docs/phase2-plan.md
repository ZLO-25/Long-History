# 第 2 期計畫：擴充中國與中西對照（2026-10-25）

## 一句話

把中國從「3 張錨點」擴充成完整的一條軌道（約 +30 張卡），時間軸改成西方在上、中國在下並列，並新增「中西對照」功能：每張卡可以指向另一邊結構相似的卡，沒有就寫「無適當對照」。


## 1. 功能

| 項目 | 內容 |
|---|---|
| 中西上下並列 | 時間軸兩條軌道等高、各自分列；滑鼠移到一張卡時，另一軌的「對照卡」一起亮起並畫連線 |
| 中西對照欄位 | 卡片新增 `counterparts`：指向另一軌的卡 id、一句說明「哪裡相似、哪裡不同」、來源；找不到就寫「無適當對照」，不硬湊 |
| 對照頁 | 卡片頁新增「中西對照」區塊；結構對照檢索可勾「只看中國／只看西方／兩邊都要」 |
| 地圖 | 新增視野按鈕「地中海／中國／歐亞」；中國段的疆域沿用 historical-basemaps（示意）；中國地點座標以 Pleiades 為優先，沒有的用維基百科座標並標明精度 |
| 路線 | 中國段只畫有資料根據的線：張騫路線、秦直道、靈渠等先標「經過的站點」，站與站之間沒有古道資料時用點線並標「路線不詳」，不畫成確定的路 |
| 驗證 | validate 新增檢查：counterparts 指向的卡要存在、要在另一條軌道、要有說明 |
