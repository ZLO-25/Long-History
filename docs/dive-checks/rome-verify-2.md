## 故事線缺邊（event-conflict-of-orders → war-samnite）

做法：**在 `event-conflict-of-orders` 加一條 effects**，沒有改 `data/storylines.yaml`。

```yaml
- { id: war-samnite, rel: 背景, why: 平民是羅馬軍隊的主力，前 367 年起也能當執政官；薩莫奈戰爭就是這樣的羅馬打的。連年戰爭帶來的收入也反過來緩和平民的不滿，誰推動誰看法不一。, src: [s1, s3], disputed: true }
```

- 依據：該卡既有的 s1（維基 Conflict of the Orders，本輪重開）寫了三件事：貧窮平民是軍隊主力；前 367 年起每年至少一名執政官是平民；連年戰爭給平民工作、收入與榮譽，緩和了處境。該卡內文原本就有「平民是軍隊主力」「貴族與富裕平民合成新統治階層」。維基 Roman Republic 也寫前 367 年後形成新的統治階層 nobiles。
- 沒做到的：規劃裡提到的 Cornell《The Beginnings of Rome》與「前 326 年廢除債務奴役」沒有找到可開啟、且明白這樣論證的來源（維基兩個條目都沒寫前 326 年；MIT OCW 講義只把兩件事並列；大英百科頁面只開到開頭）。所以這條邊**只寫「條件」**，並標 disputed：是內部和解讓羅馬能擴張，還是擴張緩和了內部矛盾，方向本身就有不同看法。
- 請主執行緒決定：若覺得仍太弱，替代方案是把 `war-samnite`、`war-first-punic` 從故事線拿掉並另補 `event-conflict-of-orders → war-second-punic` 的邊，但那條更難找來源；查核者認為現在的寫法較穩。日後能開到 Cornell 或 Forsythe 的書頁時，可把 src 換成學術來源。

## 教育面意見

- 術語：執政官、元老院、保民官、獨裁官、公敵宣告、元老院最終決議、公地、釋奴、萬民法都有 key_terms 與生活例子，國高中生讀得懂。本輪補了騎士階層、法務官／裁判官、財務官、騎兵長官、十一抽一。
- **譯名不一致**：praetor 在站內有「法務官」「裁判官」「大法官」三種。本輪把這 7 張卡的「大法官」改為「法務官」，羅馬法卡保留「裁判官」並加「又譯法務官」。請主執行緒決定全站用哪一個。「護民官」已統一為「保民官」。
- 「誰不算數」：共和成立、格拉古、馬略蘇拉、羅馬法四張寫得實在；十二銅表法原本只談平民，已補女性與奴隸。
- 這 7 張卡沒有選擇題欄位，選項分布留待單元查核。
