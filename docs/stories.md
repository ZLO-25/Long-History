# 故事（data/stories/）

每條故事線（`data/storylines.yaml`）配一篇**可以一口氣讀完的故事**：5–15 分鐘、1,500–4,500 字。
故事線原本是「一站一站＋兩站之間的因果說明」，適合查、不適合讀；故事把同一條路寫成連貫的文章，讓國高中生先融入、再記得。

```
 故事線（骨架）                      故事（血肉）
 站1 ─[促成]→ 站2 ─[回應]→ 站3      開場畫面 → 第 1 節 → 第 2 節 → … → 回答開場的大問題
 每站是一張卡                        每節對應一站或幾站，每段都標出處
```

## 三條鐵則（歷史學者）

1. **不寫新史實。** 故事裡每一件事（人、年代、數字、因果、引文）都要是卡片上已經寫明、而且卡片有標來源的內容。先用這條故事線各站的卡；需要時可以用資料庫裡其他卡。卡片沒寫的，就算你知道也不寫。
2. **每一段都標出處**，格式 `[卡片id:sN]`（sN 是那張卡 `sources` 裡的 id），放在它支持的那句話後面。出處要標卡片上支持這件事的那個來源，不要隨便挑一個。
3. **不替古人加戲。** 不編對話、心理活動、天氣、表情、場景細節。要畫面感，就用卡片上本來就有的細節（例如商鞅的「徙木立信」）。卡片說「據《史記》」「傳說」「史家看法不一」的，故事裡也要保留這層語氣；卡片的 `misconceptions`（常見誤解）不可以寫反。

另外：
- 不寫李彔、哈拉瑞等思想家的解讀（專案規則：只留直接論述，故事裡一律不放）。
- 兩站之間怎麼接，以卡片 `causes`／`effects` 的 `rel` 和 `why` 為準：「背景」不要寫成「導致」，`disputed` 的要寫出「史家看法不一」。
- 一手史料引文只能用卡片 `learn.primary_source` 或內文裡已有的引文，用 `>` 引文段落，並交代出處（誰、哪本書）。
- 敏感題目（二二八、戒嚴、殖民、戰爭）用卡片的用詞與數字，不加形容詞渲染，不替任何一方下道德結論。

## 怎麼寫才好讀、記得住（資深教育家）

- **讀者**：臺灣國中到高中生。句子短，一句一件事；專有名詞第一次出現時用一句白話解釋（可用卡片 `learn.key_terms` 的說法），並用 `**粗體**` 標出，全篇粗體不超過 8 個。
- **開場**：用一個具體的畫面、一個反差或一個謎題開始（都要來自卡片），在第一節就把故事線的大問題（`question`）丟給讀者。不要用「自古以來」「眾所周知」這種開頭。
- **每一節**：對應一站（或相鄰的兩三站）。小標題要像章回標題，讓人想往下讀（例：「一根木頭換來的信用」），不要只寫事件名。每節結尾留一個鉤子，把讀者帶到下一節；這個鉤子就是兩站之間的因果。
- **一條主線**：全篇抓一個反覆出現的線索（例如「錢」「信用」「誰接手了爛攤子」），每節都回到它，讀者才記得住。
- **數字與年代**：只留撐得起故事的，每段不超過兩三個；年代寫西元（例：前 356 年、1949 年）。
- **比喻**：可以用學生生活的比喻幫助理解，但要明講是比喻（「就像…」），而且不可以用比喻偷渡卡片沒有的史實。
- **結尾**：最後一節回答開場的大問題，並點出「這只是其中一條路，每一站還有別的原因」。不說教、不喊口號。
- **`remember`**：3 條左右、每條一句話，是讀完該帶走的重點（因果，不是年代清單）。
- **`think`**：2–3 個開放式問題，沒有標準答案，最好有一題連回今天或讀者自己。這兩欄也只能根據故事內容，不加新史實。
- 語氣：像一位會說故事的老師在跟學生講，不是課本，也不是網路文章。不用「讓我們」「小編」「你知道嗎？」，不用表情符號，不用破折號（——）串句子。

## 檔案格式

`data/stories/<故事線 id>.md`：

```markdown
---
story: story-qin-han
hook: 一根木頭、一場四十萬人的戰爭，和一個只活了十五年的帝國。
remember:
  - 第一條重點。
  - 第二條重點。
  - 第三條重點。
think:
  - 第一個問題？
  - 第二個問題？
---

## 一根木頭換來的信用 {event-shang-yang-reform}

前 359 年，原本是衛國公族的商鞅來到秦國，得到秦孝公信任。[event-shang-yang-reform:s1][event-shang-yang-reform:s7] 據《史記》，新法公布前，他在都城南門立了一根三丈長的木頭……[event-shang-yang-reform:s9][event-shang-yang-reform:s11]

> 令民為什伍，而相牧司連坐。（司馬遷《史記．商君列傳》：把百姓編成什、伍，互相監督、一人犯罪同組連坐。）[event-shang-yang-reform:s11]

下一段……[event-shang-yang-reform:s1]
```

- `hook`：入口按鈕下的一句引子，≤60 字，不放出處標記。
- `## 小標題 {卡片id}`：大括號裡是這一節講的站（可以多個，用逗號分開）。**故事線的每一站都要出現在某個小節的大括號裡，順序和故事線一樣**。開場或結尾的小節可以不寫大括號。
- 內文只用三種東西：`##` 小節、段落（空一行分段）、`>` 引文。不用清單、表格、圖片、其他層級的標題。
- 每一段（含引文）至少一個 `[卡片id:sN]`。
- 字數（不含出處標記）1,500–4,500；站多的故事線寫長一點，但寧可精簡。每分鐘以 300 字估算。

## 檢查

```
npx tsx scripts/check-stories.ts story-qin-han   # 只檢查一篇：字數、每站都有、每段有出處、出處存在
npm run validate                                  # 全站檢查（含故事）
```

程式只能擋「沒有出處」和「出處不存在」；出處是否真的支持那句話，要靠另一位沒參與寫作的查核者逐段對照卡片。

## 畫面

- 故事線頁最上面有「📖 讀故事（約 N 分鐘）」；故事線清單、學習首頁的每條故事線都標閱讀時間。網址 `?story=story-xxx&read=1`（學習模式 `?mode=learn&story=story-xxx&read=1`）。
- 閱讀頁：單欄、大字、行距寬；上方有進度條與字級切換；每一節標出對應的站，可以打開卡片；出處是小數字，文末列出全部來源；最後是「記住這幾件事」「想一想」，以及「一站一站看因果」回到故事線。
- 建置時每篇輸出成 `public/data/stories/<id>.json`，打開才下載；`index.json` 的故事線只多了 `read: { minutes, chars, hook }`。
