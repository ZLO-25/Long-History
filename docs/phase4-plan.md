# 第 4 期計畫：今日對照層（2026-10-25）

## 目標（用我的話說）

前三期都在講過去。第 4 期要在同一張地圖上疊一層「今天」：今天世界上有哪些咽喉要道和供應鏈，和歷史卡片的結構相似。每一筆今日資料都必須寫清楚「資料截至哪一天」，因為今天的數字會過時，歷史數字不會。

```
歷史卡片                     今日對照層（新）
赫勒斯滂糧食航線  ◄──相似結構──►  土耳其海峽／黑海穀物
埃及穀物運羅馬    ◄──────────────►  蘇伊士運河
勞里昂白銀、鹽鐵官營 ◄──────────►  關鍵礦物（例如稀土）供應集中
        │                                │
        └── 結構標籤相同 ───────────────┘
                                 每筆都標「資料截至 2026-xx-xx」
```

## 1. 內容（每一筆都上網查證、附來源）

**當代咽喉要道（約 6 處）**：霍爾木茲海峽、麻六甲海峽、蘇伊士運河、曼德海峽、土耳其海峽（博斯普魯斯／達達尼爾）、巴拿馬運河。每處寫：

- 位置
- 經過什麼、量有多大（例如每日石油通過量、占全球貿易的比例），每個數字都附來源與年份
- 近年中斷事件
- 對應的歷史卡片與結構標籤
- 「不可類比的差異」
- 資料截至日期

**當代供應鏈（約 3 條）**：黑海穀物出口、石油經霍爾木茲、關鍵礦物（稀土）。格式沿用第 3 期的物資鏈，節點多了「資料截至」，地圖上可以播放。

**來源優先序**：美國能源資訊署（EIA）、聯合國貿發會議（UNCTAD）、國際貨幣基金的 PortWatch、國際能源署（IEA）、各運河管理局官網，再來是路透社等主要媒體。

## 2. 介面

- 地圖加一個「今日對照層」開關。打開時用另一種樣式（菱形標記）顯示今日咽喉，旁邊寫「資料截至」。
- 點今日咽喉會打開說明面板：數字、來源、資料截至、對應的歷史卡片（可以點過去）。
- 歷史卡片頁新增「今日對照」區塊，列出結構相似的今日咽喉或供應鏈。
- 結構對照工作頁：勾選的結構標籤如果符合某個今日咽喉，也一起列出。

## 3. 規則

- 只寫結構與已發生的事實，不預測、不給投資建議。
- 每一筆資料都必須有 `data_as_of`。超過 18 個月的資料，validate 會警告「可能過時」，畫面上也會用灰色標示。
- 每一個今日項目至少要連到一張歷史卡片，並寫出「相似」與「不同」。
- 結構標籤只能用詞表裡的詞。
