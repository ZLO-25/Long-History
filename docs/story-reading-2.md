# 故事閱讀體驗第二輪：翻頁、增修、加強記憶（2026-11-11）

ZL 的意見：故事線的故事「每次畫面出現的字太少，要一直往下滑」；請調整版面，並再檢視內容，讓故事通順、合理、真實，重要的地方更詳細（必要時可到 25 分鐘），注重閱讀體驗與記憶。以歷史學者、UI/UX 專家、教育者三個角色完成。

## 二、加強記憶（教育者）

```
 開頭                讀的時候                    讀完
 「這篇故事會走過」    每節最後一條色帶            考考自己（答案先蓋住）
 1 → 2 → 3 → …       ｜記住｜這一節的因果一句話    → 記住這幾件事 → 想一想
 （先有地圖）          （邊讀邊收）                （先回想，再看重點）
```

- **先有地圖**：第一頁列出會走過的每一站與年代，可以點了跳過去。
- **每節一句「記住」**：寫在故事檔裡，小節最後一行 `★ …`，全站共 180 多條。
- **考考自己**：每篇 4–5 題，問因果不問年代；答案先蓋住，想過再點開。讀完馬上回想，比再讀一遍記得久。
- **段落合併**：原本很多一兩句就換段，現在平均一段 120–220 字，一件事講完才換段。

## 三、內容（歷史學者＋教育者）

24 篇全部重新檢視、增修，再由沒參與寫作的查核者逐段對照卡片（第二輪查核紀錄追加在 `docs/story-checks/<id>.md`）。規則不變：只用卡片上有來源的內容、每段標出處、因果強度照卡片、不放思想家解讀。

- 總字數約 84,500 → 約 118,000；每篇 11–24 分鐘（原 8–15 分鐘）。加的字集中在「為什麼會變成這樣」的關鍵轉折，過場的站維持精簡。
- 例子：商鞅變法拆成「罰、賞、管」三塊講清楚；高平陵之變一步一步寫；戰後臺灣把「時間往回撥」的地方標清楚並排出真正的年代順序；日本戰國逐站分開「當時的記錄」和「後來的戲劇、小說」；爭議數字（內戰、韓戰、柏林圍牆、越南饑荒、二二八等）並列口徑。
- 第二輪查核共修正約 70 處，最常見的仍是：★ 或考題寫得比正文肯定、串場句把「背景」寫成因果、自譯白話加了料。全部已改。
