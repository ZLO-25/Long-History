# 第 3 期計畫：經濟曲線＋物資鏈（2026-10-25）

## 目標（用我的話說）

前兩期回答「發生了什麼、在哪裡、跟誰像」。第 3 期要補上「錢與東西怎麼流動」：

```
  時間軸 ──────────────────────────────────────►
  ┌ 經濟曲線：人口、人均產出、貨幣成色（只畫有來源的點，不補線）
  └ 物資鏈：  產地 ──► 加工 ──► 運輸 ──► 集散 ──► 消費（地圖上動畫）
```

## 1. 經濟曲線

**資料來源與誠實原則**

- **Maddison Project Database 2020**（Bolt & van Zanden）：在本專案的年代範圍內，Maddison 只提供西元 1 年與 1000 年兩個時間點（義大利、希臘、埃及、西班牙、土耳其、中國等）。程式只畫這兩個點，**不在中間補線**。取得方式：Our World in Data 在 GitHub 上公開的 MPD 2020 CSV（Maddison 官網與 dataverse 在這個環境連不上，網址都會附上）。
- **戶口與人口普查記錄**：例如漢代戶口統計、羅馬奧古斯都的公民普查。這些是「官方登記數字」，不是實際人口，會在圖上標明。
- **貨幣成色**：羅馬第納里烏斯銀幣的含銀量變化、漢代五銖錢的重量規定，作為「貨幣貶值」結構的實際數據。
- 每個點都可以點開，看到數值、單位、性質（估計／登記／實測）和來源網址。查不到的就不畫，不推估。

**介面**：時間軸下方新增可收合的「經濟曲線」面板。它和時間軸共用同一條年代刻度，縮放、平移會一起動。可以切換人口、人均 GDP、貨幣成色三個指標。點擊資料點會跳到相關的卡片。

## 2. 物資鏈

- 新增 `data/chains/chains.yaml`，每條鏈是依順序排列的節點：地點、角色（產地／加工／集散／運輸／消費）、一句說明、來源。
- 兩個節點之間如果已經有畫好的路線（古道、航線、站點），動畫就沿著那條線走；沒有的話就畫成點線，標「路線示意」。
- 預計 6 條鏈：
  1. 勞里昂白銀 → 雅典鑄幣 → 艦隊與貿易
  2. 埃及穀物 → 亞歷山卓 → 海運到羅馬（奧斯提亞）→ 配給
  3. 西班牙橄欖油（Baetica）→ 雙耳瓶 → 羅馬泰斯塔喬山
  4. 漢代絲綢 → 河西走廊 → 中亞（中段路線不詳）→ 羅馬
  5. 鹽鐵官營：產地 → 官營作坊 → 各郡
  6. 大宛馬 → 漢朝
- 物資卡上加一顆「播放物資鏈」按鈕。地圖上會有點沿著鏈移動，旁邊顯示目前走到哪一個節點、那個節點的說明與來源。
- 中國與西方的鏈各自成立，不硬配對。只有絲綢這條鏈是真的跨越兩邊。

## 3. 驗證規則（validate 會擋）

- 每個經濟資料點都必須有：年份、數值、單位、性質、來源；年份要落在本庫的範圍內。
- 物資鏈的每個節點都必須有座標、來源，並且要連到存在的物資卡；用到的路線 id 必須存在。
