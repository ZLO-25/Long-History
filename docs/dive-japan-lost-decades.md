## 二、曲線的數據從哪裡來

本環境連不到世界銀行 API、FRED、日本內閣府與 e-Stat，網路查詢額度也用完，所以只用能從 GitHub 直接下載的整理版資料表：

| 曲線 | 數據 | 來源 |
|---|---|---|
| 每人平均產值（實質，2011 年國際元） | 1985–2018 | Maddison Project Database 2020（Bolt & van Zanden 2020，CC BY 4.0），Our World in Data 在 GitHub 的整理版 |
| 物價漲幅（消費者物價年增率） | 1985–2024 | 世界銀行 FP.CPI.TOTL.ZG，Open Knowledge「datasets」專案整理的 cpi.csv |
| 總人口（百萬人） | 1985–2024 | 世界銀行 SP.POP.TOTL，「datasets」專案整理的 population.csv |

- 只畫有數據的年份，不補點；每人平均產值只到 2018 年（Maddison 2020 版的最後一年）。
- 人口曲線的縱軸不從 0 開始（圖下方有寫），否則 1.2 億上下的變化看不出來。
- 原本想放日經指數年底收盤與政府債務，但沒能打開可核對的來源，所以沒放。

## 三、查核

- 三位查核者（未參與寫作）查了 10 張新卡與兩個單元，全部通過。
- 主要修正：
  - 沙林事件傷者：維基開頭寫約 1,000 人視力受損、50 人重傷，正文寫 5,510 人送醫，兩個數字並列；常見的「約 6,000 人」找不到來源，不寫。
  - 半導體協定：Kaufman 原文說南韓晶片市占上升「大概跟協定關係不大」，卡片原本加引號的字句不是原文，改成忠實轉述；華盛頓郵報那句是 1991 年的標題，不是社論引文。
  - 安倍經濟學：英文維基寫消費稅「2015 年調到 10%」是錯的（後來延後），卡片不寫日期；刪掉三句沒有來源的評論；補上 2008 年、2009 年與 2011 年地震後的 GDP 數字。
  - 2024 結束負利率：日銀新聞稿沒有「17 年來首次升息」，卡片不寫。
  - 零利率卡：「歐美借鏡日本」改成來源說的「後來採用類似政策」。

## 四、已知限制

- 網路查詢額度不夠，部分次要來源沒有重新打開（每張卡的查核紀錄都寫明了），例如日經指數幾個數字（2024-02-22 收 39,098.68 點等）、東日本大地震的部分統計。
- 學者漢字名「清水谷諭」「松永信雄」是依羅馬拼音寫的，沒找到可開的日文頁面核對。
- 「日本三十年薪水都沒漲」這個常見說法，沒有找到可以核對的長期薪資統計，卡片寫「來源不足」。
