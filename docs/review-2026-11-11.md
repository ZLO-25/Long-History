## 四、效能

### 做了什麼

```
之前                                      之後
index.json  1,045 KB（gzip）──────────▶  626 KB（−40%）
  含：查核筆記、單元每一步全文、               只留畫面第一屏要用的；
      今日對照文字                            其餘搬到 index-detail.json（背景下載）

古道 awmc-roads 517 KB：一進站就抓  ──▶  年代在 640 年以前才抓，而且等瀏覽器空閒

?card=… 連結：等 1.4 MB 內文才看得到 ──▶  先抓那張卡自己的小檔（幾 KB），馬上能讀
?story=…&read=1：等 1.4 MB 內文     ──▶  故事檔自己帶出處，不等內文

卡片圖片：載入後版面往下跳           ──▶  先照原圖比例留位置

人群圖層：每次開都重建 7,600 個點    ──▶  只建一次，之後只是顯示／隱藏
```

1. **核心資料再瘦身**（`scripts/build-index.ts`）：`learn.crosscheck`、`today_hook`／`non_analogous`、單元 `steps` 全文與 `crosscheck` 移到 `index-detail.json`；`index.json` 只留單元每一步的骨架（類型＋指到哪張卡）。`App.tsx` 的 `mergeDetail` 把單元內文併回去；學習紀錄頁改成等內文到了再顯示。
2. **每張卡一個小檔** `public/data/cards/<id>.json`：`index.html` 看到 `?card=` 就先抓它，`App.tsx` 先把這張卡併進去。
3. **故事閱讀頁不等內文**（只改 `App.tsx`／`LearnApp.tsx` 的等待判斷與 `index.html`，沒有動閱讀頁本身）。
4. **古道延後載入**（`MapView.tsx`）。
5. **圖片**：`data/image-sizes.json`（70 個 Commons 檔的原始寬高）→ 建置時寫進 `images[].w/h` → `Images.tsx` 用 `aspect-ratio` 留位置、`decoding="async"`。新增圖片時要在這個檔補寬高（沒有也能顯示，只是不留位置）。
6. **人群圖層只建一次**（`MapView.tsx`）。
