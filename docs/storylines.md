# 故事線（data/storylines.yaml）

故事線是**沿著前因／後果箭頭走出來的跨時代路線**，回應使用者「卡片像孤島、缺連貫故事」的回饋。

```
 站1 ──[促成：why]──▶ 站2 ──[背景：why]──▶ 站3 ──▶ …
        ↑ 這段說明不是故事線自己寫的，而是站1、站2 卡片上的 causes／effects
```

## 規則

1. 每兩站之間必須有一條「前一站 → 後一站」的因果關係（寫在任一張卡的 `causes` 或 `effects`）。沒有就 validate 報錯：先去卡片補因果、附來源，故事線才接得起來。
2. `question` 是開場的大問題（學生會好奇的那種）；`blurb` 只說這條線怎麼讀，不放史實細節。
3. 至少 4 站。站的順序大致依時間；後一站整個發生在前一站之前會被警告。
4. 故事線只是一條路：頁面底部提醒學生「每一站還有別的原因和後果」，避免單線史觀。

## 和「學習單元」「主題標籤」的差別

| | 回答的問題 | 怎麼串 |
| --- | --- | --- |
| 學習單元 | 一段歷史要怎麼一步步學（有練習） | 老師安排的課程順序 |
| 故事線 | 一件事怎麼引出下一件事 | 因果箭頭 |
| 主題標籤 | 同一種東西在各時代的樣子 | 依年代排列 |

## 畫面

- 研究模式：頂端「故事線」按鈕、網址 `?story=story-xxx`；地圖標站序、時間軸只亮故事線上的卡。
- 學習模式：首頁「順著一條故事線、一個主題往下走」、頂端「故事線」按鈕（桌機顯示「〰 故事線」）、網址 `?mode=learn&story=story-xxx`。
- 卡片上「這張卡在這些故事裡」會列出它所在的學習單元與故事線、第幾站、上一站／下一站。
