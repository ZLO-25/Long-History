ZL 問：網站有沒有講越南的占婆？越南和柬埔寨好像有類似的文明，也和印度有關，請補全。

## 一、新增內容

- **15 張卡**（全部摘要卡＋學習區塊，每張有一手史料：梁書、隋書、新唐書、宋史、明史、清史稿、真臘風土記，取自 GitHub 維基文庫鏡像逐字核對）
  - 印度化：event-indianization-sea、tech-brahmic-scripts-sea、event-srivijaya、war-chola-srivijaya-1025
  - 柬埔寨：event-funan、event-chenla、event-khmer-empire、building-angkor-wat、war-cham-khmer-1177、social-angkor-zhou-daguan、event-angkor-decline
  - 占婆與越南：event-champa、building-my-son、war-nam-tien-champa、event-mekong-delta-vietnam
- **2 個學習單元**：unit-angkor（吳哥窟為什麼拜印度神？）、unit-champa（占婆去哪裡了？）
- **3 條故事線**：story-india-sea、story-angkor、story-champa
- **7 張勢力示意圖**：1000、1200、1306、1471、1698、1757、1835 年（`npm run basemap -- IC` 產生越南、柬埔寨省界底圖，`npm run power` 轉成 geojson）
- **新的史**：柬埔寨史、占婆史；「文明」篩選加柬埔寨、占婆，印度加朱羅王朝，東南亞加室利佛逝
- 54 個新地名的英文對照（data/labels/names-en.yaml）

## 二、查核

- 三個獨立查核 agent 各查 5 張卡，全部「通過（有修正）」，每張卡都有 crosscheck 紀錄。
- 單元另由一個獨立查核 agent 逐步對照卡片。
- 查核抓到的錯誤舉例：俄厄出土的是羅馬「金質獎章」不是金幣；611 年碑是最早有年代的「高棉文」碑，不是東南亞最早；「魯般墓＝吳哥窟」只是推測；周達觀是 1296 年出海、1297 年回國；南進沒有「為了防中國才往南」的來源。
- 仍無法查證、已在卡片中改成保守說法的：注輦＝朱羅（中文史書沒寫明）、頓遜的位置（改成「可能在馬來半島」）。
