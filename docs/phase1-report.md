## 4. 已知問題與限制

1. **主要大道是「沿地圖集古道找最短路徑」**：線條每一段都落在《巴林頓地圖集》畫出的古道上，但地圖集沒有標每段屬於哪條大道，所以程式是在相鄰兩站之間找古道網上的最短路。少數地方可能走到平行的支線（見 6.1 節）。
2. **地圖集古道約 2,000 段沒有標時代**：地圖上把它們當成從希臘化時代起才出現（推定），滑鼠移上去會寫「未標時代」。
3. **海路沒有「真實航跡」**：經停港有史料根據，港與港之間是「不穿過陸地的最短海路」，實際航線會隨季風改變。
4. **疆域是示意**：historical-basemaps 是粗略年代快照（GPL-3.0），邊界與年份都不精確，地圖上已標「疆界示意」。年份對應規則是「取不晚於目前年份的最近一張快照」。
5. **底圖需要網路**：OpenStreetMap 底圖要連網才看得到；離線時只有疆域與點線。
6. **程式包偏大（約 1.8 MB）**：主要是簡繁轉換字典。本機使用沒有影響。
7. **時間軸在最左邊（前 800–前 600）沒有卡**，所以那段被壓得很窄，這是非線性設計的預期結果。
8. 中國錨點 3 張是**摘要卡**，只要求核心欄位，完整度 88%。
